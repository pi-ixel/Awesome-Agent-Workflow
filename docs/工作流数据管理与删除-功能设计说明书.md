# 工作流数据管理与删除 功能设计说明书

| | |
|---|---|
| 版本 | V1.1 |
| 日期 | 2026-09-17 |
| 状态 | 已实施（迁移 0020，含浏览器全链路验证） |

## 1. 背景与目标

看板采纳率异常时，管理员无法回答"是哪个人的哪个工作流造成的"，也没有处置手段。试验性运行、非目标仓库、迭代回退、大额生成后弃用等数据长期留在统计里，导致采纳率失真（长期低于 10% 或高于 80% 均说明口径不可信）。

**目标**：管理员在管理台直接浏览全量工作流及其产出、归因，按三级粒度删除不该统计的数据；删除后所有统计口径即时出清；操作留痕可审计，误删可恢复。

**非目标**：不做"该删什么"的自动判定——一个工作流内可以有多个任务、多个 dev run 与归因，任何"只保留最新"之类的启发式都不做，判断永远由人完成；不改采集协议。

## 2. 总体结构

```
看板工作流表            管理台「工作流」tab（新增）           统计
发现异常 + 徽章  ──跳转──▶ 浏览 / 详情 / 三级删除 / 归档恢复 ──▶ 全口径即时出清
（只读）                管理台「归因」tab 保持记录视角，详情互通
```

不新增看板侧操作入口；删除集中在管理台，便于留痕与权限控制。

## 3. 管理台「工作流」tab

导航顺序调整为：总览 · **工作流** · 归因 · 版本 · 注册表 · 日志。

### 3.1 列表

- 复用 dashboard 工作流查询：人、仓库、状态（进行中/已完成/停滞）、最远步骤、dev 产出数、生成行数、归因概况、最后活动时间。
- 筛选：状态 / 人 / 仓库 / 时间窗，含"停滞超过 7 天"等现成条件；分页。
- 已删除工作流默认隐藏，可切"仅已删除"查看。

### 3.2 详情（行内展开）

步骤列表 → 每条 DevRun（有效行数、归因状态、匹配 MR）→ 归因明细，三级同屏；每级都有删除按钮。

### 3.3 三级删除

| 粒度 | 语义 |
|---|---|
| 删除工作流 | 整条工作流（含全部 dev 产出与归因）从所有统计与列表消失。适用于试验性停滞、确认放弃的运行 |
| 删除 DevRun | 删掉单条代码产出：分母去掉其生成行数，归因随之失效 |
| 删除归因 | 仅删匹配结果：该产出回到"未归因"状态（分母在、分子无）。适用于匹配结果错误的场景 |

删除必须选择理由（结构化枚举，防"删除"沦为糊弄数据的后门）：试验性、停滞放弃、非目标仓库、重复生成、生成后弃用、无法匹配、其他（必填备注）。操作人、时间、理由留痕。

### 3.4 归档恢复

已删除数据在归档视图可查（含理由与操作人），可一键恢复；恢复后重新进入统计。

### 3.5 与「归因」tab 的关系

归因 tab 保持归因记录视角的检索与操作，记录详情中补充"删除归因""删除 DevRun"入口，并可跳转对应工作流详情。两个 tab 详情互通，不重复建设。

## 4. 看板入口（只读）

工作流表（ledger--wf）行内新增：

- 归因状态徽章：已归因 / 部分归因 / 未归因 / 失败（当前需自行对比生成与归因行数）；
- 「管理」链接：携带人、仓库、时间窗上下文，跳转到管理台工作流 tab 的预过滤视图。

## 5. 统计口径

- 所有统计口径（总览、汇总、组件、人员、趋势、归因记录列表）过滤已删除数据：workflow 级删除连带其下全部 dev 与归因；attribution 级删除仅将该产出退回未归因。
- 看板页脚保留对照小字："删除前口径 X%（已删除 N 项 / M 行）"，可审计、防粉饰。
- 边界：版本运营视图（谁在用什么版本）不受删除影响——删除不改变用户实际使用的版本。

## 6. 数据与迁移（0020）

| 表 | 变更 |
|---|---|
| workflow_run | 新增 `deleted`、`deleted_reason_code`、`deleted_reason`、`deleted_by`、`deleted_at` |
| code_attribution | 新增同上删除字段组 |
| dev_run | 现有 `admin_excluded` 字段组语义升级为"删除"并全口径生效，补 `deleted_reason_code` |

理由码枚举：`trial`（试验性）、`stalled`（停滞放弃）、`wrong_repo`（非目标仓库）、`superseded`（重复生成）、`unsatisfied`（生成后弃用）、`no_match_unresolvable`（无法匹配）、`other`。

## 7. 验收

- 测试：三级删除各自生效于对应口径；工作流删除连带出清；归档恢复后重新计入；理由码必选校验；未删除数据统计不受影响。
- 浏览器验证：工作流 tab 浏览/筛选/详情/删除/归档恢复全链路；看板徽章与跳转带上下文落地；删除后看板数字即时变化。
