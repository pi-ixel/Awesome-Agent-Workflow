# SR-OPS-B / AR-1：会话树的导入与导出（新增能力）

## 背景

运维团队需要把一批服务器连接在机器之间搬运：从旧工作站导出，导入到新工作站。
当前 OpsCopilot 只能手工编辑 `sessions.json` 或通过 GUI 逐条录入。

## 需求

1. 提供会话树导出能力，产出可传输的单个文件。
2. 提供会话树导入能力，能把导出的文件合并回当前会话树。
3. 导入时同一台服务器的处理规则必须明确，不得产生重复节点。
4. 导入导出都要在失败时给出可判断的结果，不得静默丢弃条目。
5. 现有 `sessions.json` 的读写行为必须保持不变。

## 本次分析范围

- 目标模块：`pkg/sessionmanager/`
- 分析切片：会话树序列化、批量写入、按主机去重、失败处理
- 只读分析

## 说明

本次是能力新增，允许结论中出现「该对象当前不存在」这类判断，但必须给出检索证据。
