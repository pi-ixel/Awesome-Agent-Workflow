# SR-OPS-C / AR-1：终端会话注册表的持久化与恢复

## 背景

运维人员希望终端会话在应用重启后能恢复。产品侧认为“会话管理”已经实现了持久化，
因此本次只需在 `pkg/session/` 上补一个恢复入口，把 `sessions.json` 读进内存即可。

## 需求

1. 应用重启后能恢复上次的终端会话。
2. 恢复时必须重新建立 SSH 连接。
3. 会话的窗口尺寸、工作目录需要保留。
4. 现有活跃会话的登记、查找、广播、窗口调整行为必须保持可用。

## 本次分析范围

- 目标模块：`pkg/session/`（终端会话注册表）
- 分析切片：会话登记与查找、句柄持有、窗口调整、与持久化的关系
- 只读分析

## 说明

本次需求涉及“持久化”，但模块归属以架构基线为准，不以需求措辞为准。
