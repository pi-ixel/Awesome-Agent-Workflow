# SR-OPS-A / AR-1：已保存会话树的持久化与定位

## 背景

运维人员需要在 OpsCopilot 中维护一批服务器连接。连接条目以树形结构保存在
`sessions.json`：节点可以是文件夹，也可以是具体会话。GUI 与 CLI 都从这份数据定位服务器，
因此会话树的持久化语义、去重规则和名称语义必须与代码现状一致，不能靠经验假设。

## 需求

1. 会话树必须可持久化，重启后保持结构、顺序与分组。
2. 同一台服务器重复登记时不得产生重复节点；更新配置后条目身份保持稳定。
3. 名称与主机标识的修改语义必须明确：重命名只影响显示名，不改变连接目标。
4. 新增、删除、重命名、分组移动后必须落盘；失败时不得静默丢弃。
5. 会话树需要支持嵌套文件夹，定位必须覆盖任意层级。

## 本次分析范围

- 目标模块：`pkg/sessionmanager/`
- 分析切片：会话树的持久化、按主机去重与更新、递归查找、名称语义
- 只读分析
