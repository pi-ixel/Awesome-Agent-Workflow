# SR-OPS-F / AR-1：会话重命名的语义调整

## 背景

产品反馈：用户把会话重命名成别名后，CLI 仍然只能按 IP 定位服务器，体验割裂。
本次改造的目标是让重命名同时更新连接目标，使显示名与连接目标保持一致。

## 需求

1. 会话重命名后，显示名与连接目标必须一致。
2. 重命名不得产生重复节点。
3. 改造前需要先确认现状：当前重命名究竟改了哪些字段、连接目标是否会跟着变。
4. 现状确认要能支撑后续设计判断，不能把目标状态写成现状。

## 本次分析范围

- 目标模块：`pkg/sessionmanager/`
- 分析切片：重命名语义、名称与连接目标的关系、去重
- 只读分析
