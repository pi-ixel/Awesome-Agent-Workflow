# SR-OPS-E / AR-1：会话树持久化的失败可见性

## 背景

线上出现过会话树被覆盖成空数据的情况，需要确认失败路径的可见性，
判断后续是否需要调整落盘策略。

## 需求

1. 查明会话树写入失败时调用方能否感知。
2. 查明读取失败（文件损坏、权限不足）时的行为。
3. 查明文件不存在时的初始化路径。
4. 查明朝持久化之前是否保留了旧数据。

## 本次分析范围

- 目标模块：已保存会话管理（`pkg/sessionmanager/`）
- 分析切片：写入失败、读取失败、初始化、数据保全
- 只读分析
