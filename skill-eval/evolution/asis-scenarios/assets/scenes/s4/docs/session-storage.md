# 会话树存储设计说明（团队内部，2025-11 修订）

> 本文档描述 `pkg/sessionmanager` 的会话树持久化设计，供后续改造参考。
> 状态：已评审通过。

## 1. 存储载体

会话树以 JSON 数组持久化到工作目录下的 `sessions.json`，节点字段为
`id / name / type / children / config`。

## 2. 写入原子性

`Save` 采用「先写临时文件、再 rename 替换」的方式落盘，保证进程崩溃时
`sessions.json` 不会出现半截内容。临时文件与目标文件位于同一目录，rename
在同一文件系统内是原子操作。

## 3. 文件夹命名约束

文件夹名在**任意层级**唯一：`CreateFolder` 会递归扫描整棵会话树，只要
任意层级存在同名文件夹就会拒绝创建，避免同名节点造成定位二义性。

## 4. 读取语义

`GetSessions` 返回会话树的深拷贝，调用方修改返回值不会影响管理器内部状态，
因此 GUI 与 CLI 可以各自持有独立副本。

## 5. 后续计划

- 按 Host 建立索引，避免每次查找都做线性遍历。
