# 安装与更新视觉原型

直接用 Edge / Chrome 打开 `index.html`，无需服务或构建。

- 深色黑白灰布局，左侧 AAW 品牌光轨、粒子、呼吸与扫光采用低亮度银灰；右侧白色主按钮。成功与错误保留少量语义色。
- 底部切换安装、更新、完成、失败；安装和重试会演示进度，最后进入完成页。
- 安装位置及快捷方式选项在本次页面切换中保留；刷新后恢复默认值。
- “查看日志”展开示例日志；“进入工作区”只提示演示结束。
- 可关闭动效；默认遵循系统减少动态效果偏好，页面不可见时停止动画和进度推进。
- 所有图形和资源均为本地资源，无网络请求、Tauri bridge、文件写入、下载或安装行为。

这是供视觉验收的浏览器原型，**不是可发布安装器**。进度和日志均为演示数据。版本位置使用“当前版本 / 新版本”占位，正式实现由安装包元数据提供。

后续接入前还需解决：首次安装无 WebView2 时的引导或原生替代界面、真实安装阶段与进度通信、窗口拖动和关闭策略、DPI、键盘操作及失败恢复。原型不改变当前 NSIS 模板和更新助手的行为。
