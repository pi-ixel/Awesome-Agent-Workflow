# CodeAgent 用量配额

仅选择 CodeAgent 时注册侧栏额度入口和「CodeAgent 配额」设置页，由 `agents/enhancements/codeagent/credit` 扩展拥有状态，不依赖项目或会话服务。

## 展示

- 侧栏使用与其他入口相同的图标尺寸；细圆环加中央菱形。圆环以月度 Credit 的 `(total - used) / total` 绘制，满额度时完整，消耗后递减。无数据或总额为零时仅绘制淡色轨道。
- Credit 页签展示月度、每日忙时、每日闲时的已用量、上限及使用进度，单位为 `credit`。
- Token 页签通过模型选择器展示每分钟、每小时、每天的已用量、上限及使用进度，单位为 `tok`，大数采用 K/M/B 缩写。
- 不展示剩余值、剩余百分比和更新时间。缺少某个窗口时显示「未提供限额」，不将缺失数据视为零。

## 数据来源

账户接口为 `/api/v1/quota/usage`，模型接口为 `/api/v1/models/{modelId}/quota/usage`，分别按 `CPM/CPD_Peak/CPD_Valley` 和 `TPM/TPH/TPD` 识别窗口，不依赖响应数组顺序。模型 ID 按单个 URL 路径片段编码，响应中的字符串数值在原生侧归一化。

具体模型列表从 CodeAgent 的 `~/.cac.json` 中解码 `enterpriseModelOptionsCacheV3_5`，包含直接列出的具体模型及 Auto 的 `tieredModelConfig.tiers`。Auto 自身不显示为独立额度，不合并不同模型的数据，也不将 large tier 的额度冒充 Auto 的额度。无缓存时提示先在 CodeAgent CLI 加载模型列表；单个模型额度接口失败时仍保留选择其它模型的入口。

凭证读取、Windows DPAPI 解密、green/yellow 分区回退沿用账户 Credit 查询。原生命令仅开放给主窗口，前端不接触登录凭证。

## 刷新和隔离

- 启用 CodeAgent 后首次读取 Credit，在窗口可见时每五分钟刷新；打开面板时也读取一次。关闭浮框不停止 Credit 更新，圆环继续反映查询到的月度额度。
- Token 页签可见时立即查询当前模型，每十五秒刷新；切换模型立即查询。关闭浮框、切到 Credit、离开设置页、隐藏窗口或切换 Agent 后停止相应查询。
- 同类并发请求合并。切换模型或卸载扩展后，迟到结果不会覆盖当前视图。
- 原生缓存按凭证指纹及模型隔离；Credit 最短查询间隔六十秒，模型十秒，避免五分钟缓存遮蔽分钟用量。凭证变更和认证失败清空旧缓存，请求结束前再次检查身份。
- Token 上次成功结果存放在当前数据目录的 `configuration/codeagent-token-quota.json`。只使用一个文件，每个模型一条最新记录，更新时覆盖，不保存查询历史。重复结果即使查询时间、重置时间变化，也不会再次写盘；仅计数或上限变化才更新。最多保留 128 个具体模型，避免模型更替无限增长。
- 持久化 Token 缓存按当前登录凭证指纹隔离，不保存凭证。重启后仍可读取同一凭证、同一模型的最后成功结果；更换凭证不复用旧值。CodeAgent 模型缓存暂时不可读时，可从有效的持久化记录恢复已查询过的模型列表。
- Token 查询失败时静默使用有效缓存，不显示失败、剩余或更新时间；首次没有数据时显示「暂无用量数据」。传输异常也保留当前模型已显示的结果。认证失效不复用缓存，仍按原刷新周期静默重试。Credit 暂时刷新失败的处理保持原有方式。

## 验证

`tests/plugins/agents/codeAgentCredit.test.tsx` 覆盖入口注册、圆环方向、单位、轮询生命周期、迟到请求隔离及静默失败；`codeagent_credit.rs` 测试窗口解析、模型展开、路径编码、DPAPI、重复一千次结果不增写、计数变化覆盖、跨重启恢复、凭证和模型隔离、条数上限及损坏文件回退。`tests/visual/codeAgentQuota.pw.ts` 使用真实扩展视图和工作台图标栏，检查双主题、390/955px、12/14/20px 字号、模型切换、分层 Escape 和静默使用缓存。视觉 fixture 使用模拟额度，不代表在线账户额度。
