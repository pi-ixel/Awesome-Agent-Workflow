# 会话每轮文件变更

本地 CodeAgent 的 Diff 来自会话 JSONL。发送时直接派发 ACP 请求，轮末在后台按工具调用 ID 关联主日志和子代理记录。其他 Agent 可查看已保存的历史 Diff，新增轮次只在适配器提供日志来源时生成 Diff。

仅展示确认成功的文件编辑。能够重建完整前后版本时显示净增删；只有操作片段时支持单双栏预览。纯聊天、归属不明确或整轮净变化为零时隐藏卡片。文件列表先加载摘要，展开时读取正文。

## 撤销与恢复

首版提供按文件和全部「撤销」，将文件恢复到本轮开始时的实际内容：删除本轮新增文件、重建本轮删除文件，可靠重命名同时校验两个路径。不提供逐块操作或接受变更。「恢复」是撤销的反向动作，将最近一次撤销的文件恢复为 Agent 修改后的状态。

撤销复用 Desktop 危险操作确认框，默认焦点为取消。写入前检查整批文件是否仍等于最终采集版本，发现后续修改就整批拒绝；每次实际写入重新校验，Windows 通过文件句柄共享模式阻止其他写入和删除。新消息后的锁定在界面、服务与原生层同时执行；其他会话的消息不锁定当前会话，但文件版本冲突仍会拒绝覆盖。

多文件写入并非文件系统事务。中途异常会停止后续写入，持续提示已完成、失败和未执行的文件，并保留安全部分的恢复入口。操作前先保存恢复日志，异常退出后重新核对实际内容，保留无法安全确认的备份，拒绝覆盖未知版本。

每轮只保留最近一次实际撤销的恢复记录，跨重启保留。全部撤销成功后自动收起同款卡片，显示已撤销并保留「恢复」及查看 Diff；历史 Diff 内容不因工作区归零而消失。关闭成功提示也不会移除恢复按钮。异常提示复用 `Callout`，详情包含文件结果，支持查看当前文件和重新检查版本；重新检查不会写入工作区。
