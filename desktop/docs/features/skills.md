# 技能清单、操作反馈与内置技能清理

技能页按当前 Agent 的来源规则扫描用户目录、已知项目与插件技能。清单保留名称、描述、来源、启停状态和版本校验信息，不统计目录总大小或使用次数。

每个 SKILL.md 的有界读取和内容摘要仍用于校验；目录清单不传输正文，详情通过文件接口按需读取。配置内技能保留定义正文。详情中的单文件大小来自当前目录的文件元信息，不做递归大小统计。

启停通过 `skill_library_toggle` 更新对应卡片。永久删除及清除停用项通过 `skill_library_remove` 校验指定条目并返回逐项结构化结果，不全量扫描、刷新技能库。删除前保留确认框，结果通过共享右下角 Toast 区分成功、部分失败和失败。永久删除未完成时保留停用项，便于继续清除。

## CodeAgent 自动清理

本地 CodeAgent 首次完成 ACP 握手、或握手版本变化时，在创建会话前执行一次批量清理。无需额外运行版本查询 CLI，也没有常驻轮询。只有全部成功才保存当前可执行入口和版本的完成记录；失败不阻止使用，下次握手重试。未报告版本时每次检查，不将未知版本视为永久完成。

名单以 [cleanup.rs](../../src-tauri/src/skill_library/cleanup.rs) 中 21 个唯一目录名为准。仅检查用户级 `.cac/skills` 和 `.cac/plugins/cache` 中发现的插件技能来源，不处理项目、共享 `.agents`、`.claude` 或 iCode 来源。

清理拒绝带链接的来源路径；命中技能本身是链接时仅移除链接。自动永久删除不先跨盘复制到停用区。成功、部分失败及异常使用右下角 Toast 汇总；没有命中或同版本已完成时不提示。

这不是安装器监听：外部安装、升级后，在 Desktop 下一次与该 CodeAgent 完成握手时执行。远程项目不会因此清理本机技能。

## 验证

- 原生测试覆盖目录来源、版本记忆、失败重试、链接隔离、清单字段及目标校验读取次数。
- 前端测试覆盖删除确认、Toast 分类、定点更新、迟到反馈和非 CodeAgent/远端隔离。
- 架构测试禁止恢复大小统计与使用日志读取、禁止删除/启停回退为全量扫描，并约束初始化顺序及批量清理路径。
