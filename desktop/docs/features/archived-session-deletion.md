# 归档会话彻底删除

首期仅支持 CodeAgent 已归档会话的单条删除。归档管理页进行一次不可恢复确认，删除 CodeAgent 历史及附属数据，并清理 AAW 对应的会话快照、图片、草稿、批注、待发队列、标题、归档与侧栏状态；独立的历史用量统计保留。

## 能力边界

UI 调用 Project 会话服务；Project 负责状态核验、关闭空闲运行时与本地数据清理；Agents 通过可选的 `deleteSession` 能力处理厂商差异；只有 Host 适配层调用原生命令。新增 Agent 的删除能力应通过适配器扩展，不在 Project 或共享 UI 中增加厂商分支。

仍被定时任务或工作流引用的会话拒绝删除。运行、恢复、打开过程中或存在待审批、待发消息时拒绝删除；已打开且空闲的会话自动关闭并等待写入收尾。

## 执行与恢复

删除记录依次进入 `prepared → source → local → done`，在执行相应阶段前持久化。删除失败保留阶段和错误，可在归档页重试；本地清理阶段重试不会重复删除源历史。启动时在任务引用注册之后恢复没有错误的中断操作，已失败操作等待用户重试。

所有阶段的持久化记录均阻止重新打开、取消归档以及迟到目录响应重新发布该会话。原生会话数据还写入永久删除标记，拒绝迟到写入和旧版历史迁移。

CodeAgent 删除优先调用捕获的启动配置中的 CLI。所有 CLI 失败均进入经过核验的文件兜底；超时须先确认命令进程树已退出。CLI 成功后也检查并清理残留。

原生层从固定的 `~/.cac/projects` 根目录定位目标，以历史首条记录的会话 ID 与工作区核验归属，并持久化文件及附属目录身份。歧义目标、变化后的历史、符号链接、Windows 重解析点与仍被外部进程使用的会话均拒绝删除。文件操作仅限已核验的会话历史及同名附属目录，保留原生删除记录供中断重试使用。

## 验证

- 架构测试限制原生删除调用边界，并沿用现有 Agent 方言隔离检查。
- 协调器测试覆盖并发合并、失败重试、持久化失败、任务归属、空闲收尾、配置别名及迟到目录响应。
- 原生临时目录测试覆盖 CLI 失败兜底、Windows 命令脚本、进程树超时、目录联接、活跃进程与陈旧 PID、身份变化及部分删除重试。
- 浏览器测试覆盖确认取消、失败保留、禁止重新打开和重试成功。

自动测试使用临时数据与模拟 CLI。真实 CodeAgent 版本的命令交互和实际删除范围还需要在安装了 CodeAgent 的环境验收。

## 无需 CodeAgent 的界面演示

运行 `npm run dev` 后访问 `/tests/visual/sessionDeletionDemo.html`。演示使用真实设置页和归档组件，模拟两个项目的五条会话；存储仅在内存中，不连接 Agent 或操作真实会话文件。

「统一 Desktop 字体与图标缩放」可正常删除；「修复归档会话的标题丢失」首次模拟文件占用；「清理旧版图片会话缓存」首次模拟本地清理失败；「每晚接口巡检的历史会话」模拟仍被定时任务引用。失败后再次删除可体验重试，刷新页面或点击「重置演示」恢复初始数据。`?theme=light` 可直接打开浅色主题。
