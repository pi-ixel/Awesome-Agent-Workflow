## 自行决策记录

- **重试语义**：现有公共 API 只支持按范围清理，没有失败子项独立重试计划。采用“重试该范围清理”，不虚构选择性重试能力；新返回结果替换旧结果，失败不伪造回滚。
- **关闭语义**：数据按钮与顶部关闭只改变面板可见性，不取消清理任务、不删除数据、不关闭 Browser 右栏。重新打开可查看既有结果。
- **布局方案**：面板使用 `max-h-[70vh] + overflow-y-auto`，顶部 sticky 关闭区，避免长内容把关闭入口挤出视口；不重新引入原生页面绝对定位遮挡。
- **结果表达**：聚合状态和子项状态直接来自 `BrowserCleanupResult`；其他范围返回的字符串状态按原值展示，不把 Host 调用成功等同于全部子项成功。
