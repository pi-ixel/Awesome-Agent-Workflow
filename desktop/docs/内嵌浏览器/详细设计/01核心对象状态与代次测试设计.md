## 1. 测试策略

使用真实状态数据和原生页面验证运行时语义，同时以单元测试覆盖完整转换表。手工维度验证用户操作和可见状态；黑盒维度只使用 ACP/MCP/界面及公开数据；装配维度使用公共运行时入口且禁止 Mock，但不冒充数据层集成；单元维度覆盖纯函数和状态转换。

断言规范描述断言目标、比较关系、预期值和证据来源；非手工用例还必须同时提供文末的具体断言代码。断言值必须由公开入口返回值、原始响应或持久化数据直接产出，禁止中间转换或聚合。手工用例只使用可观察结果。

## 2. 测试前提与数据

- 准备会话 A/B、共享工作区、两个本地页面和可控崩溃页面。
- 能读取公开浏览器空间、标签、请求和代次快照。
- 测试操作 ID 贯穿界面、MCP、运行时和日志。
- 禁止通过直接修改内部对象制造“成功”；故障只能由公开故障入口或真实原生行为产生。

## 5. 装配测试

I01～I06 均为 `[装配]`：它们验证真实公共入口与运行时协作，但最终断言位于内存状态或页面事实，不位于落库、落盘数据层。实现类以 `Assembly` 命名且不得添加 `integration` 标记；用例编号中的 I 是稳定标识，不代表测试层级。

| 用例 | 测试场景 | 前提 | 测试步骤 | 预期结果 | 断言规范 | DeskPilot 覆盖 |
|---|---|---|---|---|---|---|
| TD-01-I01 | 页面崩溃递增标签代次 | 页面就绪且有旧请求 | 通过公共入口使页面崩溃；恢复；提交旧请求 | 标签 ID 保持，标签代次增加，旧请求失效，恢复 URL 正确 | 恢复前后 tabId 相等；新代次大于旧代次；旧请求状态为失效；来源为运行时快照 | 不需要 |
| TD-01-I02 | 用户输入使控制代次递增 | Agent 租约有效 | 通过真实原生页面提交用户输入；读取控制和请求数据 | Agent 租约失效，控制代次增加，未决请求取消，归属不变 | 控制器为用户；新控制代次大于旧值；ownerSessionId 不变；来源为状态数据 | 部分，可由 DeskPilot 输入 |
| TD-01-I03 | Agent 注入输入不触发接管 | Agent 租约有效 | 通过公开 Agent 动作输入文本；读取控制租约 | 输入进入页面且 Agent 租约保持 | 页面值包含预期文本；控制代次不变；来源为页面和状态数据 | 不需要 |
| TD-01-I04 | 子 Agent 继承父空间 | 父会话已建立 | 登记子 Agent；创建页面；结束子 Agent | 页面和数据归属父会话；子登记失效后父页面保留 | 子/父浏览器 ID 相等；结束后页面存在；子请求被拒绝；来源为状态数据 | 不需要 |
| TD-01-I05 | 关闭与创建竞态 | 页面正在异步创建 | 在创建未完成时关闭逻辑标签；随后提交创建完成事件 | 最终为关闭，无迟到可用状态，无原生孤儿 | 最终状态为已关闭；可用标签集合不包含目标；回收记录完整；来源为状态与进程数据 | 不需要 |
| TD-01-I06 | 请求完成与取消竞态 | 动作接近完成 | 分别让完成先于取消、取消先于完成 | 状态遵循实际先后，不把已完成改成已取消 | 终态与事件顺序一致；副作用字段与页面证据一致；来源为请求数据 | 不需要 |

## 6. 单元测试

| 用例 | 测试场景 | 前提 | 测试步骤 | 预期结果 | 断言规范 |
|---|---|---|---|---|---|
| TD-01-U01 | 代次单调递增 | 准备浏览器、标签和控制代次 | 连续触发换代并读取值 | 每类代次独立递增且不复用 | 新值大于旧值；其他代次不被误改 |
| TD-01-U02 | 非法标签转换 | 遍历所有状态和命令组合 | 调用状态转换函数 | 仅转换表允许的组合成功，其余返回冲突 | 实际转换矩阵与详设矩阵一致 |
| TD-01-U03 | 已关闭标签不可复活 | 标签处于关闭终态 | 提交恢复、创建完成和迟到事件 | 状态保持关闭，事件被丢弃 | 状态和标签集合不变 |
| TD-01-U04 | 控制租约唯一 | 已有 Agent 租约 | 重复申请、用户收回、再次申请 | 同时最多一个 Agent 租约；收回后旧租约失效 | 有效租约数量及控制代次符合预期 |
| TD-01-U05 | 请求终态不可逆 | 分别准备完成、失败、取消和不确定请求 | 提交后续取消、完成和失败事件 | 终态不被后续事件覆盖 | 请求终态和副作用字段保持不变 |
| TD-01-U06 | 快照代次失效 | 已有页面快照 | 页面换代后使用旧快照引用 | 旧引用返回失效，不指向新页面元素 | 错误分类为失效；新页面无读取或动作副作用 |
| TD-01-U07 | 归属校验缺参 | 分别缺少窗口、工作区、会话和请求身份 | 执行准入校验 | 每种缺失均 fail closed，无全局回退 | 拒绝结果与缺失字段一致 |
| TD-01-U08 | 快照字段一致性 | 准备多代次混合数据 | 生成公开只读快照 | 快照内所有字段来自同一代次，不混合新旧状态 | 快照代次字段一致；无旧代次字段混入 |

## 7. 覆盖、证据与退出准则

- 状态机和非法转换：TD-01-U02、U03、U05。
- 代次与迟到事件：TD-01-B02、I01、I05、U01、U06、U08。
- 用户自动接管：TD-01-M01、M02、I02、I03、U04。
- 会话和子 Agent：TD-01-B01、B05、I04。
- 关闭和竞态：TD-01-M03、B04、I05、I06。

每次执行保存操作 ID、状态快照、代次变化、请求轨迹、页面行为、进程回收和 DeskPilot 截图。任何跨会话操作成功、旧代次生效、关闭后复活、Agent 输入误触发接管或用户操作未接管均为阻断失败。
