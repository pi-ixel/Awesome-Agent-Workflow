## 1. 测试策略与约束

手工测试通过 DeskPilot 操作真实窗口和网页；黑盒测试只访问公开界面、MCP/ACP 和 CDP 控制端点；集成与装配测试使用公共宿主入口和真实 WebView2，禁止 Mock；单元测试覆盖坐标、状态、端口解析和事件转换。

所有测试先给出自然语言断言规范，非手工用例还必须同时提供文末的具体断言代码。只有落库、落盘或持久化记录断言属于集成；页面、运行时快照、进程和响应协作验证属于装配。断言值必须直接产出，禁止中间转换或聚合。

## 2. 测试前提与工具

- Windows 10/11 x64、真实 WebView2、AAW 测试实例和本地测试站点。
- 会话 A/B 各有独立数据目录；测试页支持弹窗、对话框、崩溃、存储和加载计数。
- 可采集页面截图、CDP 目标、公开状态快照、相关进程和工作集。
- DeskPilot 已获当前测试实例授权；无法操作的原生模态或系统级行为必须明确标注。
