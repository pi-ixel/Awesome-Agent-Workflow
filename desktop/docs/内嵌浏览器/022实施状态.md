## 冻结实现边界

- 复用公开 `browser_set_visible`，不新增协议命令。
- 原生显示目标页面前，隐藏同一窗口的其他已登记页面；隐藏失败时不得显示目标页面。
- BrowserPanel 在活动标签或会话退出时隐藏旧页面，面板隐藏继续隐藏当前页面。
- 边界同步先于当前页面显示；后台页面不销毁、不清理、不改变控制归属。
- 017 直接离屏激活不纳入本单改写，但其恢复行为必须回归。
