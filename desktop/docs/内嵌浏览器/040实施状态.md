- 036 的自动批准发生在 Agent 收到首次错误之后，Agent 不带 `approvalId` 重试就连续拿到新审批号。
- approval-64/66 日志证明自动批准已发生，失败感来自两次调用契约。

## P3 与实盘证据

实现：

- `security.rs` 新增 `wait_for_approval` 与 `APPROVAL_WAIT_TIMEOUT=60s`，100ms 轮询，锁外休眠；批准返回记录，拒绝 `APPROVAL_DENIED`，失效 `APPROVAL_INVALIDATED`，不存在 `APPROVAL_NOT_FOUND`，超时 `APPROVAL_REQUIRED:<id>`。
- `mcp.rs` 三个分支在缺少 approvalId 时创建审批、发出事件后进入等待，随后统一走 `validate_approval` 的会话/标签/代次/动作摘要校验并执行；显式携带 approvalId 的旧路径保留。
- 执行后统一按 `approval_id` 消费审批，覆盖本次调用内新建的审批。
- `tool.rs` 三个工具描述补充等待与超时重试规则。
