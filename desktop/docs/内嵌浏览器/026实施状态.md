## 冻结公开数据与入口

### BrowserElement

每个引用必须包含：`referenceId/sessionId/tabId/tabGeneration/url/role/text/selector/xpath/rect/style/framePath`。`rect` 为 x/y/width/height 四个有限数值；`style` 仅包含 display/position/visibility 三个有界白名单字段。URL 在 ACP 序列化前使用现有 `browserObservationUrl` 脱敏。

原生 `browser_pick_start` 读取当前标签代次并注入脚本；页面消息不能自行指定其他会话、标签或代次。原生校验后使用 BrowserSpace 的 committedUrl 补齐来源，不信任页面自报 URL。`referenceId` 由页面一次性生成，原生只接受有界字符串并随事件转发，用于草稿去重和一次性提交。

### 原生选择模式

- 唯一框和定位标签使用 `data-aaw-picker-overlay`，`pointer-events:none`，不进入业务快照。
- pointermove 切换目标并按当前 `getBoundingClientRect()` 更新；scroll/resize/DPI/缩放和 DOM 移除触发重读或隐藏。
- 选择只响应 trusted click，阻止页面业务动作；Esc 和显式 `browser_pick_cancel` 清理；页面脚本暴露公开 `__aawPickerState` 供外部黑盒读取 inactive/active、目标和框几何。
- 原生取消事件使面板退出“正在拾取”；会话/标签切换、Agent 活动和导航由面板调用公开取消入口。

### 草稿与 ACP

- `AnnotationDraft` 增加独立 `browserElements` 集合；`AnnotationDraftService` 与 `ProjectAnnotationDrafts` 增加公开 `putBrowserElements(scope, elements)`。
- `encodeAnnotationMessage(text, annotations, browserElements?)` 与 `decodeAnnotationMessage` 支持带浏览器引用的版本化消息；旧文档批注 version 1 必须继续解码。新引用使用独立“AAW 页面元素引用”头、消息 ID 和有界 JSON，原正文位于头部之前。
- Browser Workbench 订阅公开 `onElement`，校验事件属于当前前台顶层会话后，通过 `ctx.project.drafts.composer.prefill` 送入编码引用；不得直接修改 ChatInput 私有状态。
- ChatInput 将解析出的引用交给 `putBrowserElements`，渲染独立可删除芯片；发送时同时编码文档批注与浏览器引用。提交、settle、recover、rejectSubmission 和草稿迁移对两类引用保持同一事务。
- 只有用户发送才产生 ACP prompt；模型回答不是引用送达的断言来源。
