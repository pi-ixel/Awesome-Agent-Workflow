## 工程决策

| 决策 | 选择与原因 |
|---|---|
| 子 WebView API | 使用当前 Tauri 的 `add_child`，开启 `unstable` 特性；这是当前版本真实子页面能力 |
| 原生创建入口 | Tauri 命令只做参数适配，实际创建由公共宿主函数承担，UI 与 MCP 共用 |
| MCP 会话绑定 | `session/new` 前预分配唯一端点；允许绑定前完成协议握手与工具发现，真实 ACP 会话 ID 返回后绑定；所有工具调用在绑定前 fail-closed |
| 非原生环境 | 不创建 MCP 端点、不读取原生页面上下文；事件订阅为空操作，避免影响测试和 Web 开发 |
| 原生页面操作 | 使用 WebView2 CDP 完成截图、视口、站点数据与文件输入；不使用外部浏览器或 Node 浏览器进程 |
| 证据存储 | 实际 PNG 落盘，历史只保存引用；目录使用会话哈希，证据读取必须经过历史记录 |
| 用户接管 | 原生页面监听 pointer、键盘、输入、滚动和触摸事件；Agent 脚本动作不冒充用户事件 |
| 高权限动作 | 提交、脚本和上传需要动作时审批；脚本与上传审批绑定内容摘要或文件路径 |
| 坐标参数 | 使用 NativeBounds 值对象，避免多参数命令和坐标含义漂移 |
| 更新安装 | 有未决浏览器操作时显式等待，不直接终止进程 |
| 窗口刷新与销毁 | 按窗口回收其子页面、审批和端点，不按工作区误回收其他会话 |
| 测试层级 | 运行时协作使用 Assembly；只有真实文件、持久化记录或数据目录断言使用 Integration |
| 手动浏览上下文 | 尚无 ACP 会话时使用项目级 `manual:` 归属上下文，不触发隐藏 Agent 或提示 |
| Agent 总开关 | 032 起原生状态默认允许；关闭撤销端点并取消未决动作；不持久化用户主动关闭状态，重启回到默认允许；已有缺工具会话需用户确认真实重连 |
| 生命周期撤销 | ACP 关闭、连接失效、Agent 切换与重连统一撤销端点、未决请求和未消费审批；撤销同时关闭 TCP 监听器 |
| 控制冲突 | 用户新建页面归用户控制；用户真实输入后 Agent 必须经独立审批重新申请，导航和高风险入口共用控制校验 |
| 审批消费 | 提交、控制、脚本和上传批准在真实成功后一次性消费；拒绝、撤销和已消费状态不可复用 |
| 原生权限 | 摄像头、麦克风、位置和通知默认拒绝；权限按会话、站点和类型管理，站点或会话清理同步撤销 |
| 原生对话框 | 使用 WebView2 `ScriptDialogOpening`、延期句柄和 UI 线程归属；禁用默认模态框，决定校验 dialogId 与代次，超时明确取消而非默认接受 |
| 原生下载 | `DownloadStarting` 暂停原下载并登记，用户决定后完成同一延期句柄；状态、字节数和真实文件来自 DownloadOperation，不重新发起下载 |
| 分层数据管理 | 持久化分区登记，占用来自真实目录；历史分区使用不进入标签集合的维护上下文；工作区与全量清理逐项异步执行，支持取消未执行子项 |
| 子页面权限边界 | 内嵌页面恢复原生对话框函数，同时关闭 Tauri IPC；独立 WebMessage 只承担用户输入和元素拾取，真实页面调用宿主命令必须拒绝 |
| MCP 标准兼容 | 在本机 MCP 标准库实证后增加 `2025-11-25`，保留既有版本并拒绝未知版本 |
| 崩溃恢复 | 原生 ProcessFailed 取消旧请求；恢复保留标签 ID 和最后 URL、递增代次，不恢复控制授权 |
| 轮次取消 | ACP cancel 与 prompt finally 都直接清理本会话未决浏览器工作，不等待 Agent 转发 MCP 取消 |
| 协议与日志 | MCP 初始化分版本协商；未初始化工具调用、未知字段和错误 Host 均拒绝；ACP 原文在落盘前移除 Bearer 令牌 |
| 图片能力 | 端点保存 ACP 真实图片能力；不支持图片时不读取或发送 Base64，结果明确标记未读取 |
| 分区隔离 | 浏览器数据目录和原生标签使用会话 ID 的稳定哈希，避免路径字符替换碰撞 |
| 外部黑盒 | `npm run test:browser:blackbox` 只通过环境变量接收端点，使用独立 HTTP 客户端和真实文件断言，不导入业务代码 |

## D1～D6 审核后的继续实施

- D1 采用已批准的可信运行时身份方案。AAW 已实现参与者登记、活动状态校验、请求参与者归属、按参与者取消及兄弟请求隔离；通用 ACP 与 iCode 方言已接入真实开始、异常结束和父工具终态。
- 曾在 iCode 0.28.0 穿刺验证运行时 `InvocationOrigin` 注入，相关 360 条定向测试通过；该实验只证明技术可行性。用户明确 iCode 不属于本项目且禁止修改后，已将上游源码、测试和新增文件全部逆向撤回，不把该实验列作交付实现。
- Smart Test 曾执行 4051 条，4039 通过、10 跳过、12 失败；失败集中在 Windows owner-only 文件写入及既有工作流界面等待，不位于实验改动链路。真实上游主 Agent 的打开、快照和截图闭环通过。
- 真实双子 Agent 联调确认能收到两个不同的子 Agent 开始事件和 invocationId，但 ACP `session/new` 注入的动态 Browser MCP 只进入主 Agent；iCode 子 Agent 仅从各自 profile 的 `tools.mcp` 构建工具，内置 General profile 没有该配置。因此子 Agent 无法调用浏览器，选择性取消联调被这一设计缺口阻断。
- 当时 AAW 只有默认关闭的全局“Agent 浏览器控制”开关，没有独立的“允许子 Agent 操作浏览器”设置。032 起总开关默认允许；后续设计仍需把授权开关与 Agent 实际能力分开表达，不能用开关掩盖工具未接入。
- D3～D5 已确认维持原生对话框、固定下载目录和子页面 IPC 锁定策略。
- D6 新增动作领域函数、语义定位解析、真实语义/重复/禁用/ref 点击验证，以及可重复的覆盖审计工具。修正组合编号后，254 条非手工用例中 96 条有实现引用，158 条仍待补齐。

- 用户于 2026-11-12 批准采用顶层会话级平权模型：同会话主、子 Agent 共享浏览器权限、标签页、站点数据和 MCP 端点，不再要求子 Agent 可信身份登记、独立审计或选择性取消。
- 新决策取代 D1 及需求决策 C-03 中的父子身份隔离路线；不修改 iCode 源码。历史穿刺与已撤回的实验保留为证据，不作为当前交付设计。
- 基线文档修订只改变主子 Agent 关系；跨会话隔离、端点令牌、高风险审批、用户接管和会话取消保持不变。真实子 Agent 工具可得性仍是必须验证的交付条件。

## 2026-11-13 Computer Use 手工验证补充

### 有效结果

- 真实 iCode 会话中，`browser_open` 首次创建页面和 `browser_wait(30000)` 成功进入未决状态。
