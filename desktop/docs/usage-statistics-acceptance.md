# 使用统计验收覆盖

前端采集用例使用 ACP 替身，SQLite 用例使用真实数据库，页面样式用例由真实 Chromium 浏览器计算布局、样式和 Canvas 像素。浏览器样式用例的查询结果来自固定夹具。浏览器流程用例使用两个 ACP 替身和原生接口替身，在真实 IndexedDB 中暂存数据，重载后恢复，并验证两个 Agent 的数据都能进入页面。它们与原生 SQLite 测试分层执行。

## 执行方式

在 `desktop` 目录运行：

```sh
npm run typecheck
npm test -- tests/plugins/project/usageAcceptance.test.tsx tests/plugins/project/usageStatistics.test.ts tests/plugins/project/conversation/turnUsage.test.tsx tests/plugins/diagnostics tests/plugins/workbench/SettingsPage.test.tsx
npm run test:visual
cargo test --manifest-path src-tauri/Cargo.toml --lib -- --nocapture
```

Windows 默认使用已安装的 Edge。其他平台可运行 `npx playwright install chromium`，也可通过 `PLAYWRIGHT_BROWSER_CHANNEL` 选择已安装的浏览器。浏览器测试失败时会保留截图。

本次基线机器为 Windows、Intel Core i5-12500H（16 逻辑处理器）。真实 SQLite 聚合 10 万轮耗时约 1.10 秒，测试上限为 5 秒。Edge 渲染对应的聚合夹具耗时约 162 毫秒，测试上限为 2.5 秒，采样的整个页面 JS 堆约 20 MiB。堆读数包含开发环境和页面依赖。

## 用例对照

| ID | 自动化证据与边界 |
| --- | --- |
| C01–C06、C08 | 两个 Agent 各执行成功、取消、失败、缺失、零、负数、非数字、无穷、字段缺失用例，检查写入边界。有效统计使用输入输出，忽略缓存和上下文数值。无效用量与缺失用量统一进入「未返回有效用量」。 |
| C07、C13–C15、C18 | 两个 Agent 各检查临时通知不写入、并行轮次按会话和工作区归属、旧会话恢复不写入、旧会话的新轮次正常写入。覆盖 store 与统计服务的连接。 |
| C09–C12、C16 | SQLite 对两个 Agent 检查相同轮次的重复、补齐、修正、工作区与 Agent 隔离及启用时间过滤。断线重发按同一轮次键模拟。 |
| C17 | **未验收**。需要两种 Agent 的真实父子代理 ACP 样本，以及足以确认父级汇总是否包含子级的计数。现有模拟测试只能证明统计入口只消费轮次结果。 |
| M01–M05 | 两个 Agent 的结果模型优先、所选模型快照、未知模型、运行中切换、下一轮新模型。原生测试覆盖模型名称表升级后为已有记录关联名称。 |
| M06 | 仅有汇总时验证仍为一条记录，不拆分到内部模型。能识别实际模型时使用实际模型，否则按发送时所选模型归属。模型来源字段保存在统计记录中。 |
| T01–T05 | SQLite 验证结束时刻归日、恰好午夜、重启后保留时区及 23／25 小时自然日。聚合测试验证跨年、跨月和闰日补零。 |
| T06 | 恢复 IndexedDB 中待写入轮次，保留原结束时刻、模型和轮次键。已收到且成功暂存的轮次可在重启后继续尝试。 |
| A01–A05 | 基准汇总、工作区与 Agent 组合、无数据请求和旧结果隔离。工作区筛选仅保留查询层测试，页面已按后来需求移除。 |
| A06–A12 | 今天未使用时从昨天接续、断开、首次使用、单日峰值、日期窗口边界、换范围只改变趋势与模型窗口、缺失和零区分。 |
| A13–A15 | 未知模型包含有效用量、零或缺失不渲染虚构百分比、超过 JavaScript 安全整数的 Token 用 BigInt 聚合。 |
| S01–S02 | 首次建库与重新打开保留记录、起点和时区，采集测试检查历史恢复不入账。 |
| S03、S12 | 验证删除会话与项目文件后独立库仍可查及统计分类拒绝清理。覆盖存储隔离和清理接口，未通过已安装桌面端点击删除按钮验收。 |
| S04–S05 | 真实 SQLite 覆盖只读、数据库忙、SQLite 页数上限导致的磁盘满。前端用替身检查错误展示、保留待重试记录和补写。 |
| S06–S08 | 子进程在 SQLite 提交前退出，打开后仅保留已提交数据。相同身份重试及多个数据库连接并行写入有单独用例。 |
| S09–S10 | 损坏库、不支持版本和失败的结构升级保留原文件或原结构；成功升级保留数据。 |
| S11 | IPC 入参断言不含正文、缓存和上下文原始字段，SQLite 只保存统计字段。待写入队列使用同一份脱离聊天内容的记录。 |
| G01–G04 | 真实 SQLite 文件及 WAL、SHM 占用统计；实际分类注册和预览请求拒绝清理；页面没有统计展开或清理入口。 |
| G05–G09 | 原生迁移测试覆盖 WAL 模式数据库关闭后搬迁、配置与用量保留、权限/空间失败的注入、源数据变化后的过期目标及迁移后只写新路径。真实启动通过存储目录共享锁协调其他实例；测试未运行两个桌面实例互相阻塞。 |
| U01–U06 | 加载、错误、重试、切换期间防串数据、保存后更新、午夜刷新和缺失用量提示。后续需求已去掉时区、顶部空数据提示和「按所选模型统计」说明，测试按新版行为验收。 |
| U07–U08 | 浏览器验证宽窄布局、深浅主题、长模型名、真实键盘导航、月份间距、卡片和浮框颜色、分隔线、标题和时间筛选对齐、趋势绘制、存储分类展开交互及诊断卡片。 |
| U09 | 原生 10 万轮测试限制聚合耗时并断言只返回聚合行。浏览器单独限制同等聚合结果的渲染时间并记录可用的 JS 堆读数。没有把两项拼算成真实桌面端端到端延迟，也未测量聊天输入延迟。 |
| U10 | 假时钟覆盖页面挂载后的轮询和卸载后停止。真实桌面长时间运行的资源泄漏仍需耐久测试。 |

当前版本仍无法补出 Agent 从未返回的用量。对于已收到的结果，暂存队列或 SQLite 至少一方成功写入时才具备重启后恢复的条件。
