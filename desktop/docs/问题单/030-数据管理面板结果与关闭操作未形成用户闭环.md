## 1. 问题根因

### 1.1 清理结果被丢弃

`BrowserPanel.tsx:624-651` 的 `executeCleanup` 对 workspace/all 返回的 `BrowserCleanupResult` 不保存、不渲染；所有范围完成后都清除确认状态并 `setError(null)`。因此子项成功、失败、取消和聚合状态无法按设计显示，部分失败也无法重试。

### 1.2 面板高度和关闭入口不可达

数据管理容器 `BrowserPanel.tsx:965-1210` 位于普通文档流，没有有界高度、内部滚动或固定关闭区；“关闭”按钮位于所有权限、视口和清理内容之后。最大化 1936×1096 截图中该按钮已在可视区外，滚轮滚动后仍无变化。

证据：`C:/tools/deskpilot/audit/027-data-open.png`、`C:/tools/deskpilot/audit/029-data-scroll.png`。

### 1.3 测试为什么未发现

后端数据黑盒 22 项只证明清理引擎；组件测试 TD-003 只证明容器没有 `absolute`，没有验证主要按钮在真实窗口内可见、可滚动、可关闭，也没有模拟部分失败返回值检查 UI 聚合。

## 2. 已批准整改方向与实施结果

保留真实 CleanupResult 和任务状态，按子项展示成功/失败/取消/未知及重试；界面不得把返回成功调用等同于全部子项成功。数据视图使用有界滚动区域和始终可达的关闭操作，并覆盖焦点、键盘、窄窗口与其他管理视图交叉。
