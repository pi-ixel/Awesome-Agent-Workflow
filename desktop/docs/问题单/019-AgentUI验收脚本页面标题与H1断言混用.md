## 1. 问题现象

真实 Agent 已在 AAW 会话中依次完成 `browser_open`、`browser_snapshot` 和 `browser_screenshot`，最终回复“页面标题为‘AAW Browser 验证页’”。浏览器面板也显示已打开页面和 Agent 可控制状态。

脚本随后失败，因为最后一条断言要求整个界面文本包含 `AAW 内嵌浏览器实盘验证`。该字符串是测试页 H1，不是页面标题，也不是提示词要求 Agent 必须复述的最终文本。

## 2. 问题根因

`desktop/scripts/browserAgentCdp.ts` 的页面夹具 `<title>` 为 `AAW Browser 验证页`，H1 为 `AAW 内嵌浏览器实盘验证`。提示词只要求“用一句话报告页面标题”，脚本却把 H1 作为最终回复的必需文本，混淆了两个不同 DOM 字段。

循环退出条件同样依赖 H1 出现在界面文本中，导致即使真实工具调用和最终标题回复已完成，仍进入失败断言。根因在验收脚本，不在 Browser MCP、Agent 或页面。

## 3. 问题引入轨迹

脚本编写时把早期页面验证文案和标题验证文案合并为一个字符串预期；本轮真实 Agent 按页面标题作答后暴露。未归因于任何产品代码提交。

## 4. 穿刺结果

| 检查           | 直接结果                                                | 结论                 |
| -------------- | ------------------------------------------------------- | -------------------- |
| 本地测试页原文 | title=`AAW Browser 验证页`；H1=`AAW 内嵌浏览器实盘验证` | 两个字段不同         |
| 真实会话回复   | 页面标题为“AAW Browser 验证页”                          | Agent 回复满足提示词 |
| 脚本失败位置   | 最后的 H1 正则断言                                      | 失败由错误预期引起   |
| 产品页面状态   | 地址为 `http://127.0.0.1:8765/`，Agent 可控制，就绪     | 产品链路已完成       |

## 5. 解决方案（待审核）

仅修正验收契约：最终回复直接断言页面标题 `AAW Browser 验证页`；循环以三个工具调用痕迹和该标题回复齐全为退出条件。若还要验证 H1，应从 `browser_snapshot` 原始返回的节点文本单独断言，不能要求 Agent 最终回复复述 H1。

不修改产品代码，不放宽工具完成状态、截图或页面标题断言，不增加固定睡眠来掩盖问题。

## 6. 是否需要补充测试设计和测试代码

需要修订该脚本的断言设计与实现，但不需要新增产品测试场景。现有真实场景已覆盖目标能力；应保留原有关键断言，并把最终文本断言改为提示词真正要求的 title。方案须按 SDD 审核后执行，并证明旧断言在正确产品结果上误红、修订后转绿。
