# AAW Desktop 前端风格约束

适用于工作区、会话、设置和诊断窗口。优先复用相邻界面已验证的布局和交互，以 ZCode 的信息密度和控件位置为参考，保留 AAW 的品牌、中文文案及能力边界。设计评审时同时看静止画面和用户操作后的结果。

## 颜色、字号和间距

| 场景 | 实现约定 |
| --- | --- |
| 页面与卡片 | 从 `bg-base`、`bg-sidebar`、`bg-surface`、`bg-raised` 选取表面层级。普通卡片用 `border-line` 细边框，悬浮层可用已有轻阴影，行内工具按钮保持扁平 |
| 文字与状态 | 标题、正文用 `text-ink`，说明用 `text-ink-mute` 等次级颜色。错误、危险操作用 danger 系列，同时给出文字或图标。选中态复用 `rowSelectedClass` 或 `tabActiveClass`，与普通悬停区分 |
| 字体与密度 | 界面文字跟随 12–20px 用户字号，正文优先 `text-ui-base`，说明用 `text-ui-sm` 或 `text-ui-caption`，页面标题沿用设置标题刻度。等宽字体留给代码、命令等内容。复刻列表时同时比对行高、上下内边距、相邻行间距与字重 |
| 空间与滚动 | 菜单行紧凑，操作区留出可点击面积。长路径和会话标题可截断并提供完整内容。文件树、消息流和设置内容区各自滚动，长代码或表格在自身容器内横向滚动 |
| 主题与动效 | 共用语义 token 适配暗夜和暖白。处理中文字可复用消息流的流光，重连展示次数；尊重减少动效设置。批注入口的彩色边框限用于已有批注场景 |

具体 token 和字号派生方式以[主题样式](../../src/shared/styles/index.css)为准。新增颜色前先检查两套主题下同用途的 token。

## 控件怎么选

| 操作 | 使用方式 |
| --- | --- |
| 开启或关闭单个设置 | 用 `ToggleSwitch`，圆点位置和底色一起反映状态，提供可读名称 |
| 在两个有名称的模式间选择 | 用 `SegmentedControl`。从多个 Agent 选一个时用 `RadioDot`，选中状态与同一行右侧操作对齐 |
| 从较多选项中选择 | 复用 `Listbox`，展示当前值、焦点和禁用态 |
| 执行操作 | 使用语义按钮。设置行主操作放右侧，同组操作保持同高。测试连接、重新扫描等使用次级按钮，编辑路径可用铅笔图标，外部仓库链接应实际打开目标 |
| 仅图标操作 | 复用已有图标和提示，设置 `aria-label`，键盘聚焦时同样可见。悬停出现的置顶、删除等按钮应能独立点击，避免同时触发行选择 |
| 可能中断或重复执行的操作 | 点重连图标后显示简短风险及“取消／确认重连”。归档采用行内二次确认，确认期间隐藏相邻操作；成功后在消息流顶部居中提供查看和撤销 |

基础按钮、焦点环、开关和选择器见[公共控件](../../src/shared/ui/controls.tsx)。设置卡片、设置行和分段选择见[设置页部件](../../src/shared/ui/SettingsPageParts.tsx)。

## 各界面的约束

- **设置**使用带 AAW 图标的侧栏，返回工作区放在分类上方，强调整体对比但避免刺眼。更新配置独立成类。内容区采用标题、说明在左、控件在右的行布局。自动保存提示放设置页右下角，避免每张卡片重复说明。
- **会话输入框**将评论胶囊和图片缩略图放在卡片内、文本上方。图片通过粘贴或拖入添加，悬停或聚焦可移除，点击可放大，Esc 只关闭最上层预览。已发送的图片在文字气泡上方靠右显示为约 80px 的圆角缩略图；只发图片时不绘制空文字气泡。参照[输入框](../../src/plugins/project/conversation/ui/ChatInput.tsx)和[消息附件](../../src/plugins/project/conversation/ui/MessageAttachments.tsx)。
- **提问**沿用会话内问答卡，一次一题，右上角显示进度和关闭入口。发送当前题后进入下一题，最后一次提交整组。可选题可跳过，关闭结束整组。同一类交互共用组件，字段类型和协议约束决定可用操作。参照[问答卡](../../src/plugins/project/interactions/ui/QuestionPanel.tsx)。
- **提示与浮层**按操作归属定位。会话提示相对信息流居中，打开文件侧栏后仍跟随信息流。批注按钮贴近文档选区，取消选区后消失。错误说明给出可执行的下一步，例如“取回输入框”，并保留已有草稿。
- **诊断**使用独立窗口，便于边操作边观察。运行日志和 ACP 事件按时间查看，详情在同一行，溢出可悬浮查看原文。性能与运行时独立呈现。协议字段可出现在诊断中，日常操作优先使用用户熟悉的名称。

## 交付前验收

1. 在开发模式打开实际入口，检查暗夜、暖白以及 12px、默认字号、20px。打开右侧文件面板，检查窄消息流、长标题及长路径是否挤掉操作。
2. 用鼠标和键盘分别操作，检查悬停、选中、焦点、禁用、等待、失败与重试。Tab 能到达图标操作，Esc 先关闭当前浮层，返回后能继续原操作。
3. 验证操作结果。例如切到不支持图片的 Agent，粘贴截图应得到明确反馈，粘贴文字仍可用；失败消息取回后，当前草稿和附件应同时保留。
4. 涉及会话绑定、数据持久化或跨页面交互时运行对应回归。视觉评审使用同一主题、字号和窗口宽度的截图，说明已检查的平台和仍需实机验证的行为。
