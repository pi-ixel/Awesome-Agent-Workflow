# Desktop 主题与组件治理方案

**状态。** 九类控件均已按六项标准验收，组件定义、动态目标、原生用点和字号规则已接入架构门禁。初始盘点基线为主仓 `46060ce0`，验收工作树基于 `29975706`。用户切换暗夜、暖白或界面字号时，已打开的 Desktop 界面原位更新。同类控件采用一致的字号档位、颜色、圆角、边框和交互反馈，保留紧凑侧栏、常规工具栏、弹窗等有明确用途的规格。

## 总目标与范围

用户在「设置 → 外观」切换暗夜、暖白或调整界面字号后，所有由 Desktop 绘制的界面都在原处更新。维护者修改一项共享规格，就能让使用该规格的页面一起生效。后续新增页面、插件私有组件和动态注册控件也要遵循同一规则。

治理覆盖九类界面元素：命令按钮、编辑输入、选择控件、导航与列表、提示与确认、状态与统计、布局与操纵、内容与专用绘制、图标与内容标识。每个定义登记用途、实现位置和归属。基础控件还要列出规格、适用状态和用例，业务组件列出所复用的控件，第三方渲染器列出接收主题更新的入口。[逐项索引](desktop-control-inventory.md) · [分类与合并表](desktop-control-review.md)

合并遵循三档：用途、样式和交互均一致时合并实现；外观一致而行为有差异时共用呈现，让业务方保有校验、数据和提交逻辑；键盘语义或焦点行为不同的控件分别保留。紧凑与标准点击区、破坏性操作反馈和不同渲染表面都有明确用途。图标随字号缩放，点击区按批准规格验收。

表格和图表预览共用 [IconButton](../../src/shared/ui/IconButton.tsx) 的 toolbar 外观。两处使用相同的图标前景、悬停背景和焦点环主题变量，分别采用 compact 和 standard 点击区。界面字号设置继续驱动按钮内图标缩放。

## 带标签复选框

技能库、工作流、存储清理和定时任务共用 Checkbox。普通复选框的选中背景和勾号使用 info 系列主题变量，星期按圆形选择规格展示。两种规格都使用原生输入处理空格键、禁用及焦点。存储清理的标签可以同时显示名称、说明和大小。开关使用 ToggleSwitch 的滑块规格，架构测试限定这两个原生复选框的定义位置。[共享实现](../../src/shared/ui/controls.tsx) · [架构测试](../../tests/architecture/checkboxBoundary.test.ts)

在工作流面板进入「运行管理」，点击「显示已归档」文字，再按空格，可验证筛选值随勾选切换。切换外观后复查勾号与焦点环。[共享交互测试](../../tests/shared/controls.test.tsx) · [工作流页面测试](../../tests/visual/workflowCanvas.pw.ts) · [主题及字号测试](../../tests/visual/uiScale.pw.ts)

## 主题从设置到窗口

[工作台外观服务](../../src/plugins/workbench/appearance/appearance.ts)已保存主题和字号，并通过根元素切换 CSS 变量。主窗口继续以该服务为唯一可写来源。所有窗口复用同一个根元素绑定，Portal 挂到所属窗口的文档中，打开着的菜单和弹窗随该文档一起更新。切换主题只更新外观，组件身份、输入草稿、选区、焦点和滚动位置应保持稳定。

[诊断窗口](../../src/bootstrap/diagnosticsMain.tsx)和主窗口通过[跨窗口外观通道](../../src/plugins/workbench/appearance/windowAppearance.ts)共享主题及字号，由统一的根元素绑定更新。副窗口启动时先应用已保存值，订阅后请求当前快照；主窗口在设置变化及收到请求时发送最新值。退出时释放监听，诊断数据轮询只更新诊断信息。安装器独立管理，系统文件选择器等原生对话框遵循操作系统外观。

## 谁决定控件的外观

| 层次 | 维护内容 | 使用示例 |
| --- | --- | --- |
| 主题变量 | 集中在共享样式定义背景、文字、边框、焦点、选中、危险操作、遮罩等用途。每个用途在两套主题都能解析到有效值，共用值可以引用同一变量 | 调整选中色时统一修改对应变量。[主题样式](../../src/shared/styles/index.css) |
| 基础控件 | 按钮、输入、选择、开关、弹层等各自拥有外观和状态。字号档位、圆角、边框、图标和点击区归入批准的规格。调用方选择用途和规格 | 项目行与分组行的归档确认共用危险操作样式，各自保留业务校验。紧凑按钮与弹窗按钮共用焦点反馈，保留各自点击区 |
| 业务组件 | 登记归属，组合已有控件，负责数据、布局和动作。面板背景等业务样式使用语义变量 | 会话页和定时任务页使用相同规格的开关，即使来自不同插件，选中和禁用表现也一致 |
| 特殊渲染 | 由适配器把主题变量转成库所需的颜色、配置或画笔，切换后更新已有实例。固定品牌色、文件类型色登记用途，并在双主题背景验证可辨认性 | [终端](../../src/plugins/terminal/rendering/terminalTheme.ts)更新运行中的 xterm；[Mermaid](../../src/shared/ui/markdown/MermaidBlock.tsx)重新渲染图；Canvas 重绘曲线、文字及坐标轴，图例使用同一组颜色 |

以开关为例，共享实现用强调色、反色前景和普通表面分别绘制选中轨道、滑块及默认轨道，统一处理键盘焦点、禁用和字号。设置页只提供选中值、标签及回调。后续增加同规格开关，复用这个实现即可。[现有开关](../../src/shared/ui/controls.tsx)

## 组件登记和架构用例

在仓库中维护可供测试读取的组件清单。首次从实施时的主仓重新盘点。此前统计的 427 个渲染符号含别名和动态选择器，只用作查漏线索。组件身份用仓库相对路径和定义符号标识，嵌套定义加所属作用域，行号只用于定位报错。

| 登记示例 | 审查字段 |
| --- | --- |
| 基础控件 `shared/ui/IconButton.tsx#IconButton`（路径相对 `desktop/src`） | 所属模块、批准规格、使用的主题变量、适用状态、覆盖这些状态的测试 |
| 业务组件 `plugins/project/ui/ProjectTree.tsx#SessionRow` | 所属插件、实现位置、复用的控件；如经动态注册，再登记槽位和渲染目标 |
| 第三方、延迟加载与渲染适配器 | 实际来源、调用入口、更新主题的方式及验证位置 |

1. 用 TypeScript AST 检查生产源码中的组件定义和引用，包含私有组件、尚未使用的定义、类组件、`memo`、`forwardRef`、`lazy` 和 `createElement`。解析导入别名和再导出；动态槽位追到其注册目标。无法静态定位的工厂应显式登记可选目标并验证。新增定义必须在同一变更中登记，删除定义同步删除记录。CI 只报告差异，清单由评审更新。
2. 检查 TS、TSX、CSS、内联样式、SVG 填充与描边、脚本注入的样式，以及第三方绘制入口。阻止新增硬编码主题色、直接指定色值的工具类、私有主题分支及绕过批准实现的原生交互控件。允许普通语义布局、已登记的主题变量和继承文字色的图标。CSS 检查按声明及作用域解析，保留色板定义和经过登记的适配器用色。
3. 存量例外逐项记录模块、所属定义、违规表达式、原因和迁移批次。同一文件出现第二个同类违规也应报错；按文件整片豁免会漏检。架构用例要证明已有控件新增调用和更换导入别名可通过，新私有组件、未登记渲染目标、裸写选中色和复制原生控件会失败。

## 迁移顺序与完成条件

| 批次 | 交付范围 | 退出条件 |
| --- | --- | --- |
| 0 · 建立基线 | 登记全部存量组件、主题入口和已知例外，启用新增项检查；记录代表性控件的双主题现状 | 门禁进入 CI，新增违规样例能稳定触发失败 |
| 1 · 打通实时换肤 | 接入主窗口和诊断窗口，迁移共享开关、复选框、归档确认和文档／会话查找高亮 | 两窗口实时一致；打开中的归档操作、选中项、高亮命中随主题更新 |
| 2 · 按控件类别迁移全量调用方 | 按钮和输入、选择器、菜单和弹窗、设置行、徽标与提示依次收口。每类先对照共享控件确定规格，再迁移所有插件中的调用点 | 已登记规格有状态用例，所属类别的存量例外清零 |
| 3 · 特殊渲染及全局验收 | 核对终端、Markdown 代码高亮与 Mermaid、用量图表、工作流画布以及独立窗口。工作流专用表面和阴影也从主题变量读取 | 双向切换时原位更新；特殊渲染与页面控件使用同一外观快照 |

每类迁移需同时提交三类证据：

- **源码覆盖。** 架构用例核对全部调用点、登记项和已删除的例外，并继续运行[字号边界](../../tests/architecture/uiScaleBoundary.test.ts)、[图标交互](../../tests/architecture/iconHover.test.ts)和[暗色对比度](../../tests/architecture/darkContrastBoundary.test.ts)检查。
- **控件状态。** 在两套主题验证每种批准规格的普通、悬停、按下、键盘焦点、选中、禁用和错误等适用状态。检查实际计算样式、文字可读性和焦点可见性；沿用字号测试验证调整字号后的文字与图标。
- **真实页面切换。** 通过设置入口执行暗夜 → 暖白 → 暗夜。覆盖已打开的业务页、弹层和诊断窗口，以及切换后新开的窗口。使用键盘往返操作，核对草稿、选区、焦点恢复和滚动状态。终端保留会话输出，图表在数据和窗口尺寸都未变化时也应重绘。扩展[现有浏览器视觉用例](../../tests/visual/darkContrast.pw.ts)验证这些路径。
