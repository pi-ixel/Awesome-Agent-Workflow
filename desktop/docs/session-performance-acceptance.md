# 会话统计验收

入口替换输入框内、上下文圆环和模型选择器左侧的实时 tokens/s。宽窗口显示「轮数 · 工具调用次数 · 平均 tok/s」，输入框宽度小于 760px 时只显示 15px 仪表盘图标和速度。悬浮、键盘聚焦或点击打开公共白底浮层；Escape、点击外部和切换会话关闭。

## 统计口径

- 每次用户提交并触发 Agent 执行为一轮，排队未发送的消息不计入。工具调用按同轮独立 ID 去重。
- 模型用时：客户端请求发出至轮次结束，扣除工具调用和等待用户区间的并集。标签只显示「模型用时」，估算口径、网络和调度开销说明放在提示图标中。
- 工具调用用时：合并并发调用区间，再扣除等待用户区间；终态重复更新不能重启计时。
- 平均首响应（TTFT）：每轮请求发出至首个非空思考或正文的等待时间取平均。没有文本响应的轮次不参与。它不是 Agent 内部每次模型请求的首 token 时间。
- 平均输出速度：有可靠计时和实际输出用量的已结束轮次，其输出 token 总和除以对应模型用时总和。CodeAgent 使用相邻累计输出差值，iCode 使用本轮输出；缺失基线或用量不得填零或用分词估算。
- 运行中实时更新轮数、工具次数、用时和已收到的首响应；TPS 等本轮结束后更新。取消或失败保留有效耗时，有实际用量才能参与 TPS。连接替换、异常退出的未完整计时不参与平均。
- 旧记录缺少计时显示「—」，不反推时间。统计与前台页面是否可见无关。累计计数及加权计算的分子、分母独立保存在会话快照，不能因 200 条消息窗口截断而丢失。

## 自动验收

- `sessionPerformance.test.ts`：并发/授权区间、重复终态、思考首响应、零值与未知、加权速度、两种 Agent 输出口径、持久化、后台会话、取消/失败、连接替换、长会话恢复后续计。
- `SessionPerformanceBadge.test.tsx`：替换旧入口、公共浮层、15px 图标、说明不直接显示、实时刷新、点击/悬浮/键盘和会话切换。
- `sessionPerformance.pw.ts`：浏览器检查白底、可进入浮层查看说明、宽窄布局、模型和发送按钮空间、浮层不越界。

旧 `outputRate.ts`、观察开关、暂停桥接和专用 `gpt-tokenizer` 依赖均已删除。
