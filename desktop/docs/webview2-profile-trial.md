# Windows 内嵌浏览器命名配置试用

试用开关默认关闭。退出正在运行的 Desktop 后，在 PowerShell 中为这次启动设置环境变量。

```powershell
$env:AAW_WEBVIEW2_SHARED_PROFILES = '1'
Start-Process -FilePath '.\desktop.exe'
```

仅新建、没有独立目录或既有选择的会话使用共享 WebView2 数据目录。每个会话有独立的命名配置，同一会话的标签、重开和清理会继续沿用它。关闭开关影响之后新建的会话。已有独立目录保留原位置。旧版仍可使用自己的独立目录，共享模式数据留在新目录中，使用支持命名配置的版本可以再次访问。

在共享模式下，会话和缓存清理由 WebView2 命名配置执行。按站点清理走已核对的目标 WebView 和站点来源。共享目录不会按会话重复计入占用。

Windows CI 使用实际 AAW 内嵌 WebView 对照独立模式与共享模式。每组分别启动 1 个和 3 个会话，各重复三次，报告进程数和私有内存中位数。试验用的环境入口只编入 CI 自检程序，发布试用的便携程序采用正常编译入口。
