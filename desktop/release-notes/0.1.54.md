# AAW Desktop 0.1.54

发布日期：2026-11-20

## 内置浏览器与设置

- 浏览器和定时任务设置移入「Agent 能力」，排在「会话与审批」之后。 [#426](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/426)
- 关闭会话时回收关联的原生浏览器视图。仅对隐藏且空闲的标签降低 WebView2 的内存目标，并按标签同步导航、加载状态和可视区域。 [#429](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/429)

## 诊断与原生操作

- 内置浏览器标签打开时，诊断窗口可以查询和清理日志，主窗口也可以正常上报日志、状态快照并执行诊断探针。 [#427](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/427)
- 修复同一场景下的终端启动、ACP 启动、CodeAgent 额度查询和强制退出。终端启动失败时显示具体原因。日志上报超时后可限量重试并按批次去重，诊断页会区分上报延迟、暂停和原生写入失败。 [#430](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/430)
