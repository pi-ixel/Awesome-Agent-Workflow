# AAW Desktop 0.1.12

发布日期：2026-11-04

## 更新链路验证版本

- 本版仅提升 Desktop 版本号并更新发布说明，沿用 0.1.11 的全部功能与更新栈溢出修复。
- 用于从已手动安装的 0.1.11 实测下载更新、点击“重启更新”、安装覆盖和重新启动的完整链路。
- 从 0.1.11 更新完成后，可在设置中确认当前版本为 0.1.12。

## 旧版升级提示

- 仍在使用 0.1.9 或 0.1.10，且点击“重启更新”会崩溃时，请先手动覆盖安装 0.1.11，再使用本版本验证自动更新。
- 提供 Windows x64 安装包和便携版，更新清单继续使用 Ed25519 签名校验。
