# AAW Desktop 0.1.69

发布日期：2026-11-28

## 会话

- 启动时优先从本地索引显示会话，Agent 在后台继续同步。自动标题和最后活动时间存入本地会话元数据，重启后仍按最近活动排序，手动标题优先。[#533](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/533)
- 信息流中 `text` 块里独占一行的文件或目录路径可以直接点击，支持跳到文件指定行，保留块内原文和复制结果。[#535](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/535)

## 技能

- 技能页精简扫描，详情按需读取，删除和启停后更新对应条目，并显示操作结果。[#534](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/534)
- CodeAgent 首次连接或版本变更时清理指定的用户级内置技能。[#534](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/534)
