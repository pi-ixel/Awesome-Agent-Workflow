# AAW Desktop 0.1.47

发布日期：2026-11-18

## CodeAgent 用量配额

- 额度浮框新增 Credit / Token 页签，可选择具体模型，查看每分钟、每小时、每天的 Token 已用量与上限。Auto 路由下的具体模型分别展示额度。见 [#382](https://github.com/pi-ixel/Awesome-Agent-Workflow/issues/382)。
- 侧栏圆环随月度 Credit 消耗递减，统一图标大小、`credit` / `tok` 单位、浮框排版和加厚的圆角进度条，移除更新时间及剩余信息。
- Token 页签打开时每十五秒刷新当前模型；关闭后停止轮询。保留各模型最近一次成功结果，查询失败时静默沿用，本地缓存不追加历史、不重复写入相同结果。

## 会话与连接

- CodeAgent 归档会话支持单条彻底删除，清理源会话及对应的本地会话数据，保留历史用量统计；运行中或被定时任务、工作流引用的会话会阻止删除，失败后可重试。见 [#394](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/394)。
- 普通会话、定时任务、模型选项读取共用 ACP 连接总额度，避免超过四条连接；切换 Agent 时保留任务连接，减少任务被连带中断。见 [#392](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/392)。
- Windows 重复启动会恢复已有窗口；修复点击系统通知可能打开第二个 Desktop 的问题，并保留会话定位信息。见 [#393](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/393)。

## 界面修复

- 修复定时任务删除确认弹窗的内容贴边问题，统一留白、删除按钮样式和取消焦点。见 [#391](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/391)。
- 对齐侧栏头像、图标和底部提示的行高与留白。
