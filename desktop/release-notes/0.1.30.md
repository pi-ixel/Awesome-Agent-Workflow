# AAW Desktop 0.1.30

## 界面

- 项目路径、编辑器、热力图等悬浮提示统一为浅色主题白底、深色主题随卡片配色。用量明细和任务预览沿用统一的浮层样式。
- 「每日 / 每周 / 累计」「近 7 天 / 近 30 天」及同类分段控件统一尺寸和选中样式，支持键盘切换。
- 消息底栏的复制与用量图标统一为 15 × 15 px 和同一灰度。用量角标用紧凑数字显示输入与输出之和。

## 用量统计

- 「本轮用量」浮层显示含缓存的精确总量，保留输入和输出，新增缓存读取和缓存命中率。CodeAgent 对相邻两轮的累计值取差，命中率为本轮缓存读取除以本轮总量。ICode 直接取该轮回包，命中率为缓存读取除以本轮输入。缺少缓存数据或分母为零时，对应指标显示「未知」。
- CodeAgent 使用统计按相邻轮次的 `totalTokens` 差值累计，计入缓存用量。缺少基线、计数回退或历史记录缺少总量时，保留轮数并标记总量未知。
- 模型用量环图按 Agent 和模型 ID 归并。同一模型的历史名称归到一项。同名但 ID 不同的模型保留原名，可悬停或聚焦提示图标查看 ID。
