# AAW Desktop 0.1.19

发布日期：2026-11-06

## 修复与改进

- 修复 CodeAgent 子工具同时经主会话和子代理通知发送时重复显示的问题。按同一会话内的工具 ID 合并，兼容两条流及父工具先后到达；保留标准流独有的参数和输出，不隐藏主代理的独立工具。
- CodeAgent 工具没有有效输入参数时，输入区展示标题并明确标为“操作描述”；后续有效参数替换兜底，空更新不覆盖已有参数。主工具与子工具规则一致，ACP 原文日志保持不变。
- 子代理回复和思考复用主消息流组件；工具记录复用普通工具卡，统一 Markdown、字号、复制、命令输出和标准编辑差异呈现，保留折叠入口、失败状态与未收到结果提示。

兼容逻辑位于 CodeAgent 增强模块；普通 ACP Agent 不启用 CodeAgent 的输入兜底和双流归属规则。验证使用本地自动化协议对端与 UI 回归，不代表真实 CodeAgent 已完成实机验收。
