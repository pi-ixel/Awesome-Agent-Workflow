# AAW Desktop 0.1.38

发布日期：2026-11-16

## 问题修复

- 展开或收起右上角的会话状态卡时，状态卡浮在信息流上方，消息宽度、输入框和滚动位置保持稳定。([#354](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/354))
- 右侧工具栏以固定宽度滑动，动画结束后对话区只重新布局一次。收起时信息流滚动条淡出，跟随最新消息时保持贴底，上翻阅读时保留当前位置。([#355](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/355))
- CodeAgent 在设置中选定「引导」后，按发送或回车即可提交，输入框移除重复提示和选择器，普通排队列表在引导模式下收起。([#356](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/356))
- 「交互行为」并排演示排队和引导时的输入框，动画连续播放。上一条消息明确尚未发送时，客户端把原文和附件与补充合成一轮。建连失败时可一起取回，断线或取消超时导致执行结果未知时可分别取回。([#357](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/357))
