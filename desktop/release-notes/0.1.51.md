# AAW Desktop 0.1.51

发布日期：2026-11-19

## 会话技能

- CodeAgent 每次打开 `/` 菜单时，读取全局和当前项目的技能。菜单按来源列出可关联的技能，并从 Agent 命令中移除重复项。技能管理页会说明技能文件的具体检查结果。
- iCode 的技能候选显示技能描述，同名时优先使用当前项目的描述。
- 通过菜单选中的技能在输入框和已发送消息中显示为粉色渐变引用，重载会话后可恢复。Agent 继续接收 `/技能名`。

## 技能管理

- 支持单独回收 CodeAgent 插件目录内的技能。见 [#410](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/410)。
- CodeAgent 使用次数按日志的 `skillName` 统计。见 [#411](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/411)。

## 工作流

- 工作流节点使用普通会话，可从运行详情直接打开。停止后可以在会话里提交结果，继续运行时会采用已提交的结果。运行管理与工作流库调整为同级入口。见 [#412](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/412)。
