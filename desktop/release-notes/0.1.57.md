# AAW Desktop 0.1.57

发布日期：2026-11-23

## 会话与吐字

- 首段即时显示，后续按字素分批上屏，突发输出更快追平。后台会话、最小化窗口和上翻历史时暂停吐字动画，接收与保存继续进行。回到会话底部或恢复窗口时直接显示最新内容。未闭合的代码块先显示原文，闭合后再显示代码工具。 [#448](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/448)
- Windows WebView2 固定回放中，单前台和四会话场景的 CPU 时间分别降低约 51% 和 69%，流式私有内存峰值增量降低约 65% 和 67%。约一万字集中到达时，末批上屏从约 1.5 秒缩短至约 0.2 秒。

## 浏览器与资源诊断

- 并行浏览器会话按活跃状态调整 WebView2 内存使用，并引导 Agent 在同一查询中复用标签。轮次预检失败后清理资源，未就绪或缺少原生句柄的标签不会阻断其他可用标签。 [#449](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/449)
- 资源诊断页可展开 Desktop 工作集构成，以同一采样时刻展示最近一轮峰值，并独立列出 Agent 的资源占用。
