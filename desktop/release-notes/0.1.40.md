# AAW Desktop 0.1.40

发布日期：2026-11-17

## 会话管理

- 会话重命名支持点击其他位置保存。侧栏在原标题处编辑，回车保存，Esc 取消。([#362](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/362))
- 会话支持通过右键菜单和行尾按钮加星。星标会话带金色五角星，排在所属项目顶部，并按最近消息排序。([#362](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/362))

## 界面优化

- 权限审批弹窗只展示一次待执行命令，把工具和来源会话信息放到预览下方。默认聚焦「拒绝」。([#363](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/363))
- Desktop 的主按钮、重点标题和键盘焦点统一使用主题中性色，主按钮在浅色主题用深底，在深色主题用浅底。([#363](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/363))
