# AAW Desktop 0.1.3

发布日期：2026-11-02

## 优化

- 更新下载支持 Windows 系统代理配置。
- 使用 GitHub 官方资源接口获取签名更新信息和安装包，提高下载可靠性。

## 修复

- 区分网络连接失败、服务未部署和暂无签名更新等状态，方便定位更新检查问题。

## 安装说明

- Windows x64 用户可下载安装包，或解压便携版后手动替换。
- 需要 WebView2 和单独安装的 ACP Agent。
- 安装包通过 Ed25519 签名更新信息及 SHA256 校验，暂未提供 Windows Authenticode 签名。
- 不支持自动更新的旧版本需要先手动安装。
