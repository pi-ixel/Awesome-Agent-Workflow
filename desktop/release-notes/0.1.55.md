# AAW Desktop 0.1.55

发布日期：2026-11-22

## 插件管理

- 技能卡片支持独立启停、目录大小和更清晰的详情浏览。更新后的技能图标覆盖侧栏、卡片和会话引用。 [#432](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/432) · [#438](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/438) · [#440](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/440)
- 统一管理 iCode 当前配置的原生 MCP 与 Desktop 全局 MCP。服务列表与详情并列，窄窗可单独打开详情。新增弹窗支持表单、JSON 导入预览和推荐模板，并保留各页签草稿。 [#439](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/439)
- MCP 检测结果按配置版本保存，重新检测失败时保留上次的工具清单。内置浏览器和 Desktop HTTP 服务支持工具级控制。技能与 MCP 的操作只更新对应条目，减少页面闪烁；两页的顶部操作栏和全局开关样式同步统一。

## 浏览器与会话

- 浏览器标签恢复改由 Desktop 原生存储保存，保留按项目和会话恢复，并纳入诊断存储管理。 [#436](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/436)
- 修复 Windows 系统代理下 iCode 访问内置浏览器本地 MCP 的连接问题。 [#437](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/437)
- 统一会话列表的运行指示，并修复浏览器工具标题串入会话的情况。 [#434](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/434)

## 设置

- 修复勾选存储范围时设置弹窗跳动。 [#435](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/435)
