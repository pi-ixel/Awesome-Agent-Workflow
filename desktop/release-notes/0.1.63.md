# AAW Desktop 0.1.63

发布日期：2026-11-25

## 会话与变更撤销

- 升级时，会话数据按 Agent、项目和会话分别存放。迁移中断后可以继续，同时保留浏览器恢复记录和 Diff 撤销历史。修复同一会话有多份快照、旧版 Windows Diff 路径导致迁移卡住的问题。 [#481](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/481) [#482](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/482)
- 打开项目时会在后台准备变更基线。准备期间可以输入，大项目首次可发送前可能需要等待几分钟。准备完成后，每轮只处理改过的文件，撤销本轮可保留发送前的修改。 [#482](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/482)

## 浏览器、Git 与技能

- 内置浏览器可在操作后检查预期结果，帮助 Agent 判断页面是否完成了预期变化。 [#478](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/478)
- Git 刷新时只列出未跟踪文件，打开文件的变更审查后再统计行数。会话状态卡只汇总已跟踪文件的变更。技能列表、文件预览和启停操作也可以独立执行。 [#483](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/483)
