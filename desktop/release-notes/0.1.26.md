# AAW Desktop 0.1.26

发布日期：2026-11-11

## 功能变更

- 在「设置 → 会话与审批」中可选择「过程与结论」或「仅结论」。两种方式提供同步动态预览，显示用户输入、Agent 的处理过程和最终回复。
- 输入栏显示上下文用量和当前可见会话的输出速率。输出速率每 200 毫秒刷新一次，使用最近 200 毫秒收到的输出估算。
- 新增本地存储管理，可查看占用、调整存储位置和清理可回收数据。

## 问题修复

- Agent 运行时，最新处理卡片的标题会显示流光。需要用户确认或运行结束时停止。
- 信息流预览在播放期间保持固定尺寸，消息依次淡入，「仅结论」中的过程会平滑收起。
- 「恢复默认设置」使用与应用其他确认弹窗一致的样式，支持按 Esc 取消。
- 修正 CodeAgent 问答表单中的占位提示，优化存储提醒和警示颜色。
