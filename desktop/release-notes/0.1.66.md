# AAW Desktop 0.1.66

发布日期：2026-11-27

## 会话与文件

- 信息流中的文件、目录和网页引用可在 Desktop 内打开。目录会在文件树定位并展开，多个插件支持同一引用时可选择打开方式。 [#506](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/506)
- 按 Agent 和项目记录会话归属及元数据。 [#508](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/508)
- 文件树搜索框统一使用紧凑布局，字号与其他搜索控件一致。 [#513](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/513)
- 横排流程讲解图的各段纵向居中，箭头与内容对齐。 [#509](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/509)

## 项目与界面

- 侧栏用文件夹和显示器区分本地与远程项目，用叠层表示多目录。图标随 Desktop 字号缩放。 [#515](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/515)
- 支持从项目快捷操作重命名。 [#517](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/517)
- 会话组的行尾状态点与归档图标对齐。 [#518](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/518)
- 修复远程多目录项目的打开、恢复和保存。 [#514](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/514)
- 统一远程主机界面字体，并支持打开项目目录。 [#507](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/507)
- 从最小化恢复时保持视口和侧栏宽度稳定，并改进布局动画回归用例。 [#516](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/516) [#512](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/512)

## Agent 与登录

- 模型选择支持搜索，控件焦点样式统一。 [#505](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/505)
- SSO 认证使用正式网关。 [#510](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/510)
