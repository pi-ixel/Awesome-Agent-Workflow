# AAW Desktop 0.1.42

发布日期：2026-11-17

## 界面优化

- 「界面字号」同时调整文字和图标大小，主窗口和诊断窗口实时同步。按钮、输入框和文件树可容纳放大的内容。([#371](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/371))
- 工作流、设置、诊断和用量页面的分段控件统一使用透明底与细圆角外框，选中项用独立胶囊标识。([#372](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/372))

## 问题修复

- 安装取消或失败后可返回修改安装位置。选择磁盘根目录会提示并允许重新选择。数据存储设置会依次处理目录选择和保存，避免旧结果覆盖新目录。([#368](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/368))
- CodeAgent 收到当前会话的有效回传后才中断当前轮并发送引导。当前轮先结束时直接补发。等待中的消息可撤回编辑，首次回传前断线或失败时可从队列取回。([#369](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/369))
- Windows 确认退出后先隐藏主窗口，再卸载工作台，修复退出过程中的短暂黑屏。([#370](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/370))
