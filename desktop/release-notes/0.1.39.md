# AAW Desktop 0.1.39

发布日期：2026-11-16

## 问题修复

- 点击 Windows 会话或工作流通知时，优先唤起发出通知的窗口。已有 Desktop 运行时，转发失败也不会另开窗口。应用完全退出后，多个同时到达的通知最多启动一个窗口。([#359](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/359))
- CodeAgent 首条消息独立发送。提前提交的补充按顺序静默暂存，收到同一首轮的 Agent 进展后再引导，首轮先结束则直接发送。审批介入时把补充放回输入框，发送异常时保留原文和附件。正常结束即使没有正文也不会提示取回草稿。([#360](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/360))
