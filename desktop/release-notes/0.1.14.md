# AAW Desktop 0.1.14

发布日期：2026-11-05

## 更新内容

- 将 ICode 的私有协议、子代理、用量、技能、编辑差异、设置与压缩历史逻辑集中到增强模块，完善普通 ACP Agent 的独立运行和多 Agent 状态隔离。
- 修复会话标题、运行状态、未读与置顶等跨 Agent 混用问题，保留不完整会话列表刷新前已知的历史会话。
- 支持粘贴、拖入多张图片，提供缩略图、移除与放大预览；发送后的图片以靠右的小尺寸缩略图展示。
- 图片草稿按会话保存到 IndexedDB，重启后可恢复；取回消息时恢复文字和图片并保留已有草稿。每条最多 5 张，单张 10 MB、合计 20 MB；不支持图片的 Agent 会明确提示。
- Git 行数统计失败时保留文件状态列表，并提供独立的统计失败提示和诊断信息。
- 增加标准 ACP 禁载 ICode 的协议链路测试、方言对照和架构依赖守卫，补充异常、恢复、跨 Agent 隔离的覆盖矩阵。

## 验证范围

本版使用本地自动化验证协议与界面逻辑，未调用真实模型；未实现的 ACP 能力保持明确拒绝或降级，不新增客户端 fs/terminal 等能力。
