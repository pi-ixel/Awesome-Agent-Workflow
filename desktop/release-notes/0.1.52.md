# AAW Desktop 0.1.52

发布日期：2026-11-19

## 内嵌浏览器

- Desktop 新增内嵌浏览器，支持多标签、网页导航和页面缩放。
- 可以拾取网页元素并引用到当前会话。Agent 可通过会话级 Browser MCP 工具操作浏览器，相关操作按会话权限和审批设置执行。见 [#413](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/413)。

## 会话

- 恢复输入框的图片附件缩略图尺寸。粘贴大图也会保持为 64 × 64 像素，点击缩略图可查看大图。
