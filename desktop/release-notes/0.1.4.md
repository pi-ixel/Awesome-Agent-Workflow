# AAW Desktop 0.1.4

发布日期：2026-11-03

## 新功能

- 诊断改为独立窗口，可在主窗口操作的同时查看日志，重复打开会聚焦已有窗口。
- 新增本地持久化日志，支持级别、模块、关键词、时间与操作关联查询，以及历史记录导出。
- 更新按钮支持悬停查看 Markdown 更新日志，版本和发布日期一目了然。

## 优化

- 更新按钮采用更醒目的绿色圆角样式，调整字号与尺寸；更新弹窗加入 AAW Desktop 图标。
- 补充会话、ACP、文件、终端和后台更新的操作阶段、耗时及错误信息，便于日常排查。
- 日志自动按 7 天、100MB 上限清理，详细日志模式开启 30 分钟后自动恢复。
- 诊断窗口复用主窗口的运行状态、内存曲线与对话存储读数，关闭诊断不影响采集。

## 修复

- 修复更新弹窗操作按钮不够清晰、浅色主题下下载按钮难以辨认的问题。
- 诊断不再占用设置页面，避免查看日志时无法继续操作主窗口。

## 安装说明

- Windows x64 用户可下载安装包，或解压便携版后手动替换。
- 安装包继续使用原有 Ed25519 更新签名密钥，升级校验方式不变；暂未提供 Windows Authenticode 签名。
- 需要 WebView2 和单独安装的 ACP Agent。
