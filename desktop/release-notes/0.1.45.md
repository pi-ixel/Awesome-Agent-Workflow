# AAW Desktop 0.1.45

## 定时任务

- 新增本地定时任务，支持一次、每天和每周运行，按电脑时区触发。任务使用保存时的 Agent 配置，并自动读取可用模型和强度。
- 每次运行创建独立会话。从任务运行记录查看结果或处理审批。任务执行期间错过或跳过的计划，以及异常退出时中断的运行，均保留记录。
- 新增系统托盘菜单。「关闭窗口时留在托盘」默认开启，已保存的设置继续生效。收进托盘后，定时任务继续运行。

## 界面与交互

- 统一「新建会话」和「新建任务」按钮的样式。左侧导航以一条竖线与内容侧栏分隔。
- 统一浮层阴影与下拉菜单动效。弹窗下拉菜单会根据可用空间决定展开方向，避免被底部裁切。
