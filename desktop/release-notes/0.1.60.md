# AAW Desktop 0.1.60

发布日期：2026-11-24

## 远程项目

- 支持通过 SSH 添加远程项目，在 Desktop 中浏览和编辑远端文件、查看 Git 状态与差异、使用 OpenSSH 终端，并从会话中调用远程项目工具。新增「设置 → 远程主机」用于管理连接。Windows 发布包随附远程项目所需的 OpsCopilot sidecar。 [#465](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/465)
- 修复远程项目的文件操作。文件树隐藏本地资源管理器操作，复制路径时返回真实远端路径，并跳过依赖本地文件系统的整轮变更跟踪。 [#467](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/467)
- Windows 便携包同时包含远程项目和工作流所需的两个服务程序。完整解压后运行 `desktop.exe`。

## 界面

- 统一新建会话与添加项目的入口，支持切换本地与远程项目。改善分段控件对比度与动效，以及明暗主题切换动画。 [#465](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/465)
