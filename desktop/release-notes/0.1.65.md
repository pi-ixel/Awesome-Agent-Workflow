# AAW Desktop 0.1.65

发布日期：2026-11-26

## 会话与文件

- Agent 回答和文件预览中的 ```visual 代码块渲染为讲解图，支持分层结构、数据流、方案对比、分步过程和可调参数的小演示，并跟随深浅主题。带脚本的图在沙箱中运行，不能联网或访问本机。 [#497](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/497)
- AAW 打开的会话自动带上可视化演示工具。Agent 需要画示意图时会先取得写法，再用讲解图代替 ASCII 字符画。原生启动的 Agent 不受影响。 [#503](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/503)

## 项目

- 项目侧栏每次展开 5 条会话并显示剩余数量，全部展开后可一键收起。星标保留在顶部，各项目独立记录展开范围。 [#498](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/498)
- 创建和编辑项目时可关联多个工作目录。新会话继承项目目录，文件树、Git 和终端可切换目录。 [#500](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/500)
- 单目录项目和多目录项目可共用主目录，各自保存会话归属，互不显示对方的会话。 [#502](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/502)
- 远程项目的 SSH 连接保存成功后才登记项目，保存失败时保留已填内容。缺少连接信息的旧项目可通过「修复连接」恢复，原有会话路径保持不变。 [#499](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/499)

## Agent

- 确认切换 Agent 后显示阻塞进度弹窗，覆盖停止工作流和切换连接的全过程。失败时可重试、复制诊断信息或退出。 [#501](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/501)
