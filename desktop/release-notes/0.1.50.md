# AAW Desktop 0.1.50

发布日期：2026-11-19

## 技能管理

- 插件管理新增「技能」和「回收站」。技能页跟随设置中选中的 iCode 或 CodeAgent，先显示全局技能，再按项目分组显示项目技能。
- 技能卡片可悬停查看描述，点击打开详情并阅读 `SKILL.md`。更多菜单提供打开目录和复制路径，复制成功时在右下角提示。
- 支持导入、批量移入回收站、恢复和永久删除。同名导入或恢复会跳过冲突项，永久删除前会要求确认。CodeAgent 插件包通过 Agent 原生方式卸载和重装。见 [#408](https://github.com/pi-pixel/Awesome-Agent-Workflow/pull/408)。
