# AAW Desktop 0.1.27

发布日期：2026-11-11

## 功能变更

- 设置页恢复分类页签，方便按类别查找设置。
- 自定义 Agent 的高级配置新增「支持自定义回答」，开启后可在兼容的选择题中输入自由文本。
- 问答输入框支持按 Enter 进入下一题或提交最后一题，中文输入法选词时不会误提交。

## 问题修复

- 统一切换 Agent、清理存储、退出应用等确认弹窗的样式。
- 存储设置和诊断页支持点击分类行展开或收起明细，清理入口统一显示为「清理」。
- 清理完成后立即重算存储阈值提醒，释放空间降到阈值以内时及时撤下提醒。
- 会话停止确认后自动关闭该会话待回答的问题卡片，失效草稿也可手动关闭。
- 修复结构化问答只填自定义答案时「发送」按钮仍被禁用的问题。
