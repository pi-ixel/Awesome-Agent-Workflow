# AAW Desktop 0.1.7

发布日期：2026-11-03

## 新功能

- 支持对 Markdown、代码和纯文本选区添加批注，作为评论胶囊加入会话，确认后统一发送。
- 未发送批注随会话草稿保存，支持编辑、删除和失败恢复；引用保留原文快照，不修改原文件。
- 点击历史评论可在“文件”页签定位原文，无需额外打开文件页签。

## 体验优化

- 评论胶囊支持悬停查看详情，批注入口采用流动彩色边框；历史评论展示在消息气泡上方。
- 会话行悬停即可置顶或取消置顶。
- 调整审批菜单的字体、图标与间距，底部审批入口补充图标。
- 包含自 0.1.6 发布后合入的通用 ACP 模型显示修复和设置页开关样式优化。

## 安装说明

- 提供 Windows x64 安装包和便携版。
- 沿用原有 Ed25519 更新签名密钥；暂未提供 Windows Authenticode 签名。
- 需要 WebView2 和单独安装的 ACP Agent。
