# AAW Desktop 0.1.5

发布日期：2026-11-03

## 优化

- 设置页统一使用主界面的字体、颜色、按钮和输入框样式，减少卡片嵌套，调整分组标题与行间距。
- 通用、Agent、工具路径、会话与审批、归档管理采用一致的布局；更新设置改用清晰的设置行和开关。
- Agent 启动参数收进高级配置，编辑已有 Agent 或提交出错时自动展开；收起后仍保留已填写的参数。

## 修复

- 修复窄窗口、大字号下 Agent 状态标签与操作按钮拥挤重叠的问题。

## 安装说明

- Windows x64 用户可下载安装包，或解压便携版后手动替换。
- 沿用原有 Ed25519 更新签名密钥；暂未提供 Windows Authenticode 签名。
- 需要 WebView2 和单独安装的 ACP Agent。
