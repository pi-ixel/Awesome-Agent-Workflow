# AAW Desktop 0.1.34

发布日期：2026-11-14

## 功能变更

- 切换 Agent 时展示各阶段、耗时和连接握手进度；可最小化到侧栏，失败时可复制诊断信息并重试。
- 优化工作流运行页和画布布局，收拢次要操作，窄面板中可在节点详情和流程图之间切换。
- 确认关卡支持直接查看待处理节点并自动定位；完成运行后可查看交付说明和运行总结。
- 优化工作流侧栏的节点顺序、出错状态和运行入口，改进产出文件展示及节点会话中的工作流说明。
- 统一工作流界面的按钮、提示、状态和导航样式，并改进 AI 编辑工作流的展示与说明。

## 问题修复

- 修正中断节点的状态及用时，运行总结仅统计实际运行时间。
- 修复切换 Agent 时无法看清连接准备进度和失败位置的问题；连续切换时保留最新选择的状态。
