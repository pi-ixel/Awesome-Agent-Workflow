# AAW Desktop 0.1.37

发布日期：2026-11-16

## 功能变更

- CodeAgent 主对话框新增「引导」。它会保存补充消息，等待当前轮取消后再发送。执行结果不确定时保留消息，避免自动重复执行。可在「会话与审批」选择默认交互行为。([#350](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/350))
- 项目栏、文件目录和右侧工具栏收展时，旁边的内容同步调整宽度。会话状态卡和右栏完整视图也增加过渡，切换时保留输入草稿。动效遵循系统的「减少动态效果」设置。([#352](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/352))
- 统一项目树和文件树的展开、收起动效。([#348](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/348))

## 问题修复

- 同步 Git 并排差异两侧的横向滚动，便于对照长行。([#349](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/349))
- 提高暗夜主题下的文字、边框和状态提示对比度。([#351](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/351))
