# AAW Desktop 0.1.58

发布日期：2026-11-23

## 会话整轮变更

- 在本轮回复末尾查看工作区净 Diff，按本轮开始与结束时的文件内容计算；此前已有的修改不会计入。支持新增、修改、删除和可确认的重命名。
- 提供收起、内嵌及放大审阅，统一视图与双栏对比可切换。双栏横向独立滚动、纵向同步；卡片采用轻量成果样式，突出文件数和增删统计。
- 支持按文件或全部撤销，并恢复最近一次撤销的改动。发送下一条消息后，上一轮操作锁定；新轮产生净变更时替换旧卡，纯聊天则保留旧卡供查看。
- 引导消息按发送时的文件状态切分统计范围；断联及重启恢复时补采集已执行的变化。无变更或执行过程中不显示空卡和计算提示。
- 撤销与恢复执行文件版本校验，拒绝覆盖后续修改；异常按具体文件和操作结果提示。
