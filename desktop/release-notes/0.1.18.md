# AAW Desktop 0.1.18

发布日期：2026-11-06

## 修复问题

- 修复内置 CodeAgent 的 ACP initialize 请求缺少 `clientInfo.version`，被严格校验的服务端以 `-32602 Invalid params` 拒绝，导致无法获取会话的问题。
- CodeAgent 现在发送 `{ name: "aaw-desktop", version: "0.1.0" }`，与现有客户端标识约定保持一致。
- 握手回归改为使用真实适配器配置，并增加严格对端测试：缺少 version 时拒绝握手，补齐后可完成握手及创建会话。此前测试使用会话层默认 clientInfo，未覆盖这一遗漏。

本次修复与 0.1.17 的 Windows shim 路径修复相互独立，不改变启动命令、安装路径或模型请求内容。
