# AAW Desktop 0.1.49

发布日期：2026-11-18

## 图标与弹窗

- 统一桌面端纯图标按钮的尺寸、点击区和悬停、键盘聚焦及按压反馈。CodeAgent 额度入口也使用侧栏规格，悬停时朝内容区轻抬。架构检查覆盖所有前端组件中的纯图标操作。
- 设置和新建定时任务的蒙层与内容同步淡入。弹窗用 220 毫秒轻微上移并回到原尺寸，避免打开时页面先闪暗。见 [#404](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/404)。

## CodeAgent 配额与归档

- 「配额」设置移到「数据与统计」。可在同一页查看 Credit 和各模型的 Token 限额，排版随可用宽度调整。见 [#402](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/402)。
- Credit 与 Token 额度查询沿用 CodeAgent CLI 的直连方式，修复系统代理导致的超时。见 [#406](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/406)。
- 归档永久删除兼容缺少初始化记录的 CodeAgent 历史。目录与会话身份通过核验时才允许删除，仍会拒绝重复候选、历史损坏和文件版本变化。见 [#401](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/401)。
