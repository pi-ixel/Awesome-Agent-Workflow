# AAW Desktop 0.1.6

发布日期：2026-11-03

## 修复

- Windows 下的 SSO 和更新请求改用系统 TLS（Schannel）及系统证书库，支持系统已信任的企业证书。
- 设置页版本号随实际构建版本更新，不再固定显示 0.1.0。
- 修复 Markdown 图片在界面重绘时重复进入加载状态的问题，保留已加载图片和已打开的预览浮层。
- 图片全屏预览中按 Esc 仅关闭图片，再次按 Esc 才收起侧边栏。

## 安装说明

- Windows x64 用户可下载安装包，或解压便携版后手动替换。
- 沿用原有 Ed25519 更新签名密钥；暂未提供 Windows Authenticode 签名。
- 需要 WebView2 和单独安装的 ACP Agent。
