# AAW Desktop 0.1.17

发布日期：2026-11-06

## 修复问题

- 修复内置 CodeAgent 自动探测后把无扩展名 shell shim 保存成 Windows 启动路径，导致“不是有效的 Win32 应用程序（错误 193）”的问题。
- 默认保持 `codeagent acp`，自动检测及重新检测只展示结果；用户点击“使用检测路径”后才持久化绝对路径。
- 兼容旧版保存的无扩展名 Windows 路径：每次启动前仅检查同目录 `.exe/.cmd/.bat` 入口。找不到支持的入口、路径失效或类型不支持时，保留配置并明确提示修改路径或清空使用 PATH，不静默换到其他安装。
- 设置页连接测试、协议自检、实际会话及连接恢复统一使用 CodeAgent 的启动校验，Windows 批处理入口继续交给共享传输层启动；Linux 无扩展名程序保持支持。

## 使用说明

- 选择内置 CodeAgent；路径留空即可使用 PATH。旧路径能在同目录找到支持的入口时直接兼容启动，也可点击“使用检测路径”保存该入口。
- 检测路径只检查存在性和支持的入口类型。请使用“测试连接”确认实际程序能启动并完成 ACP 握手。
- 本次不改变自定义 Agent 的启动约定，不修改 ICode 的路径探测规则，也不宣称已修复 CodeAgent 纯图片请求立即结束的问题。
