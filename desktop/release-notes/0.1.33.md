# AAW Desktop 0.1.33

发布日期：2026-11-14

## 功能变更

- 新版 Rust 工作流引擎接入 Desktop，替代首版 CLI 工作流；节点会话纳入标准会话管理，提供流程阶段、待回复标记、侧栏运行分组和重载续跑。
- 新增工作流库、YAML 源码编辑与校验、导入导出、脚本信任，以及通过 AI 创建和修改工作流；支持按角色指定 Agent 和模型。
- 新增检查点、回退、重跑、改道、确认关卡及启动前环境检查，配套运行管理、系统通知、用时、计划进度和运行总结。
- 新增工作流画布、适应窗口、小地图、键盘操作、子流程实例提示和跨项目运行总览；侧栏自动展开到打开的会话，支持整次运行归档。

## 问题修复

- 修复轮次结束事件提前收尾导致普通会话响应中的用量、统计记录和输出速度数据丢失的问题，同时保留外部驱动会话的运行状态更新。
- 修复 CodeAgent 同一模型的裸 ID 与带 `w3/` 前缀 ID 在用量统计中被拆成两项的问题，统一新记录和历史数据的统计身份；不修改 ACP 模型切换使用的原始 ID。
- 修复 CodeAgent 多题和数组多选表单无法输入自定义答案的问题，各题独立保留草稿，多题单选支持自定义答案与选项互斥，多选支持追加自定义文字。
- 修复多题首题仍显示发送按钮的问题：非末题显示下一题箭头，上一题采用一致样式，末题才提交整组答案；返回上一题保留答案。
- 工作流数据改存应用数据目录，避免占用 WebView 本地存储；优化错误说明并避免重复报错。
