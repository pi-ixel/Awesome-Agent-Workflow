# AAW Desktop 0.1.43

发布日期：2026-11-17

## 界面与交互

- 文件面板和独立目录标签统一使用外观里的文件树位置设置，默认靠右，可在文件面板内直接跳转到设置。Markdown 标题栏新增「预览 / 源码」切换，文件内查找统一为浮层，源码保留替换能力。大纲、文件树和会话状态折叠区复用同一动效。([#375](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/375))
- 工作台左项目栏和右工具栏从各自的屏幕边缘展开或收起，停靠和浮层共用抽屉组件。([#376](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/376))
- 统计、任务步骤和消息导航浮框从触发器一侧轻微展开，普通文字提示使用淡入淡出。统计值统一对齐，首次打开直接显示当前值，小幅刷新时末位轻微移动并逐渐恢复清晰。([#378](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/378))

## 功能清理

- 移除旧版 SDD 的 Teams 插件和 Desktop 项目工作区的健康检查入口。([#374](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/374))
