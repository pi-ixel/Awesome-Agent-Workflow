# AAW Desktop 0.1.9

发布日期：2026-11-03

## 安装与更新

- 安装时检测到正在运行的客户端，由 NSIS 原生提示框提供关闭确认；静默安装内核也会显示提示，不再无提示退出。
- 关闭失败时提示手动退出，可重试或取消；不强制结束应用进程。重试时重新检查占用状态，确认解除后才替换应用文件。
- 补充安装阶段、关闭结果和错误码日志，修复原生日志被覆盖的问题。
- 完成页明确显示“安装完成”或“更新完成”。

## 登录

- 跟随主分支修复统一身份认证流程，手动登录入口默认收起。

## 安装说明

- 提供 Windows x64 安装包和便携版，覆盖更新保留原有数据。
- 沿用现有 Ed25519 更新签名；暂未提供 Windows Authenticode 签名。
