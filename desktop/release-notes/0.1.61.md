# AAW Desktop 0.1.61

发布日期：2026-11-24

## 会话

- 模型菜单新增手动刷新。会话运行中选择的新模型会在下一条普通消息发送前应用，切换失败时保留待发消息并显示原因。 [#469](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/469)

## 工作流

- 草稿页内嵌 AI 会话，支持在流程图上打开节点精修，编辑节点提示词、结果流向和关联知识。运行时先提供知识目录，Agent 可按需读取文档。 [#473](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/473)

## 界面与 Windows

- 侧栏标题使用规整斜体显示 Awesome Agent WorkSpace，空间不足时恢复粗体 AAW。左上角采用保留原始折线的 28 px 矢量图标。
- 更新 Windows 主图标和任务栏未读角标。主图标重新采样并增补高 DPI 尺寸，未读数字采用正圆底和抗锯齿字形。 [#470](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/470)
- 统一应用内圆角规格，并放大 Windows 主图标中的品牌图案。 [#471](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/471)
