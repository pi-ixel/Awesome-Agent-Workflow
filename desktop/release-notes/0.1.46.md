# AAW Desktop 0.1.46

发布日期：2026-11-18

## CodeAgent 账户额度

- 选择 CodeAgent 时，左侧栏新增额度入口，展示月度、每日忙时和每日闲时的 Credit 已用量、总额与剩余额度。
- 从额度浮层进入设置页，可查看重置时间并手动刷新。刷新失败时显示上次成功结果与更新时间。见 [#386](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/386)。

## 企业登录

- 企业登录窗口遇到旧 Cookie 或临时网关故障时继续等待登录，保留正在输入的内容。
- 关闭登录窗口后立即恢复登录按钮。每次登录使用独立窗口，旧窗口的事件和响应不会影响重试。见 [#385](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/385)。

## 运行与构建

- 修复 Windows Agent 进程强杀时错过退出事件的竞态，减少关闭时不必要的等待。
- 前端与 Rust 校验并行运行，优化测试执行池，加快持续集成验证。见 [#387](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/387)。
- 更新代理协作指南与工作流 CLI 设计文档引用。
