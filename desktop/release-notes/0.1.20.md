# AAW Desktop 0.1.20

发布日期：2026-11-06

## 修复问题

- CodeAgent 子代理缺少输入描述时，使用父工具的有效标题展示任务描述；优先保留原始 description/prompt，忽略 Task、Agent、空标题及工具 ID 等占位内容。完成通知才提供有效标题时，在完成后补齐描述。
- 支持从父工具标准 content 读取子代理最终回复，兼容旧版 rawOutput 优先级；rawOutput 无可读文本时回落到 content。
- 生产修改仅位于 CodeAgent 增强模块，新增 10 个兼容回归用例。

本次未修改工具次数和 token 用量统计。缺少子工具归属信息时继续保留顶层工具，不按执行时间猜测父子关系；新版 CodeAgent 未发送子代理进度的情况仍需上游提供关联信息。
