# AAW Desktop 0.1.10

发布日期：2026-11-04

## Markdown 编辑与文件阅读

- Markdown 源码模式支持编辑，提供保存按钮、Ctrl+S、撤销重做及未保存提示。
- 源码与预览通过工具栏单图标切换；预览使用当前编辑内容，无需先保存。SVG 保留只读源码与预览切换。
- 切换文件、项目、关闭文件或退出前，提供保存、放弃修改、取消三种处理方式；保存失败时保留编辑内容。
- 文件被其他程序修改时，未编辑文件自动刷新；有本地修改时保留内容并提示冲突，可重新载入或明确覆盖保存。
- 源码行号栏使用与正文一致的底色，淡化行号、突出当前行；折叠箭头按需显示，保留固定占位。
- 文件大纲支持拖拽调宽、键盘调整和双击复位，并记住宽度；搜索、大纲跳转与批注继续支持源码和预览。

## 会话与界面交互

- 会话侧栏支持右键重命名，修复菜单关闭时抢走重命名输入焦点的问题。
- 聊天输入框上下文圆环改为简洁样式，悬停显示容量与可用的缓存用量信息。
- Mermaid 图表预览的鼠标滚轮改为每格约 2% 缩放，保留触摸板连续缩放和拖拽平移。
- 新建会话立即进入独立草稿，不再等待正在运行的旧会话；权限菜单、设置卡片、文件搜索、输入历史和消息区域对齐进一步统一。

## 安装说明

- 提供 Windows x64 安装包和便携版，覆盖更新保留原有数据。
- 更新包与更新说明沿用 Ed25519 签名校验。
