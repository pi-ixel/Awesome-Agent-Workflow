# AAW Desktop 0.1.16

发布日期：2026-11-06

## 新增功能

- 内置 CodeAgent，启动命令为 `codeagent acp`，支持独立配置可执行路径。请在设置中选择内置 CodeAgent；同名自定义命令仍使用标准 ACP，不自动加载方言增强。
- CodeAgent 增强支持真实工具名、子代理消息及工具进度、历史恢复、模型和会话模式切换确认，以及旧格式表单兼容。仅在明确关联时展示子代理，不根据工具标题或 think 类别推测。
- 成功且参数完整的 TodoWrite 可生成计划卡；参数缺失或失败时保留工具记录，不推测计划。支持工具文件位置跳转，轮次结束后刷新 CodeAgent 会话标题并保留手动名称。
- 诊断日志新增 `acp-raw` 原文保存、查看及导出，便于核对图片内容块、响应和私有通知。原文包含完整消息、工具参数和图片数据。

## 修复问题

- 修复在新建会话草稿中切换 Agent 后，仍使用旧 ACP 连接、首发会话未进入当前 Agent 项目列表的问题。切换后等待新连接就绪才允许发送，连接失败不回退旧 Agent，迟到连接不能接管草稿。
- 未发送草稿每项目保留一份，文字、图片及批注随 Agent 切换；兼容旧草稿迁移，已发送会话仍保持原 Agent 归属。新 Agent 不支持图片时保留附件并提示，阻止发送。
- 上下文容量为 0 或缺失时明确显示未知，保留已上报用量，不伪造百分比或将会话累计消耗当作上下文占用。
- CodeAgent 取消优先使用标准通知；等待 5 秒仍未结束时终止当前连接的进程树，保留结果未确认提示，不自动重发消息。

## 验证与限制

- 已补充 CodeAgent 方言隔离、协议异常、草稿绑定及迁移、纯图片输入框到 ACP 请求的本地自动化回归；未调用真实模型进行实机验收。
- CodeAgent 1.2605.00 的纯图片发送后立即结束问题尚未定位。本版提供完整 ACP 原文诊断供复现分析，不宣称该 Agent 端行为已修复。
- 若实时 TodoWrite 参数为空，需等完整历史回放后才能生成计划；用量缺失时不推测 token 数。
