# AAW Desktop 0.1.56

发布日期：2026-11-23

## 工作流

- 左侧工作流入口管理模板，右侧 AAW 标签页管理运行。在会话输入框用斜杠选择起点，直接在当前会话发起。运行列表支持状态筛选，以及改名、归档和删除。
- 工作流各处统一以会话执行状态为准，并明确显示阻塞原因。步骤开场白精简为工单、必读清单和结果要求。引擎重连后自动同步状态，运行时长扣除等待时间。 [#442](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/442)

## 浏览器与会话

- Windows 新会话可试用共享 WebView2 进程，每个会话仍使用独立配置。试用默认关闭，既有会话保留原有存储模式。 [#443](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/443)
- 浏览器旧快照在打开或清理时会核对项目和会话归属。修复浏览器工具标题混入 Agent 会话历史，并补齐浏览器恢复、iCode 代理、MCP 缓存和技能异步读取的回归测试。 [#444](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/444)

## 插件管理

- MCP 服务卡片居中，详情默认收起。点击卡片从右侧打开详情，换卡片时直接切换内容。宽窗并排，窄窗覆盖列表。
- 测试连接移到服务状态旁，精简检测信息。技能与 MCP 的搜索和筛选控件统一字号，并增加抽屉交互、减少动画和控件复用的回归测试。 [#446](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/446)
