# AAW Desktop 0.1.48

发布日期：2026-11-18

## 上下文容量与额度

- 上下文容量、CodeAgent Credit 和 Token 额度共用柔和的浅蓝进度条，百分比固定在条内右侧。额度的已用量与上限在右侧成对显示，容量和 Token 数值使用 `k`、`M` 等缩写。
- 每个会话在 SQLite 中只保留一条上下文快照。有效上报会更新这一条记录，重新打开会话即可恢复容量与占用。异常上报、历史回放和迟到读取不会覆盖已保存的新值。

## 标题栏、侧栏与文件

- 工具栏和导航栏图标接入共享轻抬动效。会话标题栏的项目文件夹和重连图标向上轻抬，会话状态卡的「更多」和「收起」按钮统一外观与动效。见 [#397](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/397)。
- 提升浅色和深色主题下侧栏账号头像的辨识度。见 [#398](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/398)。
- 修复目录在 Windows 资源管理器中显示失败的问题。见 [#396](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/396)。
