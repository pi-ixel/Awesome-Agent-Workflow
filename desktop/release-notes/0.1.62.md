# AAW Desktop 0.1.62

发布日期：2026-11-24

## 文件与变更审查

- 文件面板和目录标签支持粒子换侧。在外观设置点击「左侧」或「右侧」，可见的文件树立即开始换侧，保留选中文件、展开状态和滚动位置。系统启用「减少动态效果」时直接换侧。 [#477](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/477)
- 优化大文件的变更审查。统一与双栏视图按需渲染可见代码行，切换视图时保留阅读位置。修复展开大量未改动行时可能出现的报错。 [#474](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/474)

## 界面与设置

- 修复鼠标停在存储明细区时滚轮无法上下滚动的问题，窄窗口下仍可横向浏览明细表。 [#477](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/477)
- 微调侧栏全称 Awesome Agent WorkSpace 的字重，使其在正常宽度下更易辨认。 [#475](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/475)
