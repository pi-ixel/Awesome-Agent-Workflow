# AAW Desktop 0.1.32

发布日期：2026-11-14

## 功能变更

- 输入框新增会话统计入口，展示会话轮数、工具调用次数和平均输出速度；悬浮或点击可查看模型用时、工具调用用时、平均首响应时间和平均输出速度，窄窗口自动收缩显示。
- 支持 CodeAgent 和 iCode：按各自用量口径统计输出速度，合并并发工具耗时并扣除等待用户的时间；会话计时及累计数据随会话保存，切换页面和恢复长会话后仍可查看。
- 统一使用统计、归档管理、设置和诊断等页面的下拉选择框样式，以及危险操作按钮和确认弹窗的样式。

## 问题修复

- 用会话平均输出速度替换原先的短时间窗口估算，移除旧实时速率采样及其分词依赖；缺少可靠计时或用量时显示未知，避免误导。
- 修复归档管理中搜索框与筛选下拉框高度不一致，统一会话统计悬浮卡片风格。
- 上下文容量比例未知时简化为“未知”，移除多余说明。
