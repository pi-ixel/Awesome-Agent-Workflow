# AAW Desktop 0.1.15

发布日期：2026-11-05

## 修复问题

- 修复发送图片后重新加载会话，文字仍在但图片缩略图消失的问题：此前历史加载会用 Agent 回放内容替换本地消息，回放缺少图片时无法恢复附件；现在独立保存已发送图片，在能明确匹配历史消息时补回显示。
- 修复大图片随聊天快照写入 localStorage 容易超出容量、导致后续加载缺少历史的问题：用户消息附件改为独立保存到 IndexedDB，文字快照不再重复保存图片数据。
- 图片历史按 Agent、项目和会话隔离。Agent 回放已经携带附件时保留其内容；出现重复提问且历史不完整、无法明确对应原消息时，不猜测图片归属，避免错配。

## 使用说明与限制

- 本地补图只恢复 AAW 的历史显示，不会重新发送图片或重新执行请求，也不代表 Agent 的模型上下文仍保留原图。
- 此前已经丢失、且 Agent 回放与本地缓存均不再包含的图片无法追溯恢复，需要重新发送。
- 已发送图片保存失败时会显示提示，并写入诊断日志。
