# AAW Desktop 0.1.67

发布日期：2026-11-28

## 工具与项目

- 新增个人工具中心和启动器，可在 Desktop 管理和打开个人工具。 [#491](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/491)
- 个人工具中的图片和媒体遵循工具的联网权限。 [#527](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/527)
- 五项内置 MCP 支持独立检测连接，检测成功会完成握手并读取工具列表。 [#522](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/522)
- 新建项目时可搜索并加回最近移除的项目。 [#524](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/524)
- 取消选择目录时安静返回，避免出现多余的错误提示。 [#526](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/526)

## 界面

- 统一 Desktop 的墨滴开关。圆形滑块在轨道内垂直居中，保留上下均匀的轻阴影，并覆盖两态的缩放回归。 [#529](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/529)
- 统一文字按钮的字号、排版和对齐，并加强共享按钮的架构检查。 [#528](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/528)
- 普通导航刻度使用统一的主题灰色。 [#523](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/523)
- 提示条的标题与操作按钮对齐，窄窗口下操作可整组换行。 [#520](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/520)
