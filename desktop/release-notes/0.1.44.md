# AAW Desktop 0.1.44

发布日期：2026-11-17

## 界面与交互

- 新增工作台左侧导航。AAW、会话和工作流入口共用竖向细框，项目侧栏收起后仍可切换。设置和账号位于导航底部，存储告警贴项目区底部。([#380](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/380))
- 从左侧可浏览预置、我的工作流和当前项目的运行记录，选中条目后打开现有详情。切换侧栏入口时保留当前主内容，快速切换项目时只显示当前项目的运行。([#380](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/380))

## 问题修复

- 修复已建立的 CodeAgent 会话无法及时触发引导取消的问题。补发间隔从发出取消请求时计算，当前轮自然结束时直接补发。简化待发队列显示。([#377](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/377))
