# AAW Desktop 0.1.11

发布日期：2026-11-04

## 修复重启更新崩溃

- 修复 Windows 上点击“重启更新”时，Desktop 因线程栈溢出（0xc00000fd）退出、更新助手尚未启动的问题。
- 安装包哈希校验缓冲区改为堆分配，避免异步更新任务在原生 IPC 调度中产生过大的栈帧；签名、大小和哈希校验继续保留。
- 增加更新命令异步状态大小回归测试，以及正式程序的真实 WebView2 → Tauri IPC 检查；后者在发布前确认更新命令不会使程序退出，且不会实际执行安装。

## 旧版本升级提示

- 如果 0.1.9 或 0.1.10 点击“重启更新”会退出，请下载本页 Windows x64 安装包，手动覆盖到原安装目录一次。旧程序自身的更新代码无法通过崩溃的交接流程修复。
- 本补丁包含 0.1.10 的 Markdown 编辑、大纲拖拽调宽、行号栏、重命名、上下文圆环和 Mermaid 改进。
- 同时提供便携版；更新清单继续使用 Ed25519 签名校验。
