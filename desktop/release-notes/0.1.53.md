# AAW Desktop 0.1.53

发布日期：2026-11-20

## 会话与设置

- 已发送的图片在信息流中恢复为缩略图，输入框和信息流共用缩略图样式，点击可预览原图。 [#418](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/418)
- 设置页签在首次打开时按需加载，减少打开设置时的初始加载量。 [#422](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/422)
- 统一按钮、输入框、选择器等九类控件的主题、字号和交互样式。新增架构检查，要求新组件登记并遵循共享控件与主题约定。 [#423](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/423)

## 工作流

- 流程图按阶段展示步骤状态，点击阶段可展开步骤与子流程。模板支持在节点审查抽屉查看职责、产出、结果去向和关联规范，同时调整了工作流库的导入、新建与草稿操作。 [#419](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/419)

## 内嵌浏览器与 Agent 诊断

- 浏览器受限操作遵循 Desktop 的审批默认设置。工具调用可在同一次请求中等待审批并继续执行。元素拾取支持连续选择，并减少重复计算。 [#421](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/421)
- ACP 协议诊断使用独立的临时连接，诊断过程中可以继续使用现有会话。 [#424](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/424)
