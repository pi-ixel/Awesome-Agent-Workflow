# AAW Desktop 0.1.64

发布日期：2026-11-26

## 会话与文件

- 本地 CodeAgent 根据会话和子代理日志在后台生成每轮变更，发送消息无需等待工作区快照。日志有完整文件版本时可撤销，只有编辑片段时可只读查看。其他 Agent 仍可查看已有的历史变更。 [#492](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/492)
- 加快 CodeAgent 归档删除，通过目标会话目录清理本地数据并增量更新项目索引。源历史已不存在时仍会清理归档，独立用量统计继续保留。 [#490](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/490)
- 切换项目时保留侧栏里各项目已有的会话顺序、工作流分组和展开状态，避免会话列表闪动。 [#493](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/493)
- 点击 Agent 回复中的行内绝对路径，可在右栏预览文件并跳到指定行，项目外文件也可打开。 [#494](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/494)
- 从浏览器切到审查或文件标签时，当前标签占满右栏。切回浏览器可继续查看原网页和未提交的地址草稿。 [#485](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/485)

## 工作流

- 使用 AI 新建或修改工作流时立即打开草稿和编辑抽屉。优化运行状态和步骤跟随，修复临时会话误报未读，并提示未被节点引用的知识文档。 [#476](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/476)
- 在会话状态胶囊集中显示当前工作流进度，统一加载指示器的动画节奏，改善侧栏工作流分组和会话状态提示。 [#486](https://github.com/pi-ixel/Awesome-Agent-Workflow/pull/486)
