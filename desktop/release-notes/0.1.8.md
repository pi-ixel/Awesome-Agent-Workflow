# AAW Desktop 0.1.8

## 安装与更新

- 首次安装与应用更新共用全新深色安装界面，加入蓝紫光效、品牌 Logo 动画与简洁文案。
- 安装界面显示真实安装阶段；不使用模拟百分比。尊重系统减少动态效果设置。
- 缺少 WebView2 时，先使用原生引导下载并安装运行时，再打开品牌界面；首次补装需要联网。
- 更新改为独立助手接管：确认助手就绪、等待旧进程退出、再次校验安装包、安装成功后启动应用。
- 安装失败可重试和查看日志；安装过程中禁止关闭界面。遇到仍在运行的应用时提示关闭，不强制结束应用进程。
- 保留覆盖更新方式，不新增“先卸载再安装”步骤。

## 体验优化

- 增强侧边栏会话运行指示器的颜色对比度。

## 安装说明

- 提供 Windows x64 安装包和便携版。便携版需要系统已安装 WebView2。
- 沿用原有 Ed25519 更新签名密钥；暂未提供 Windows Authenticode 签名。
- 旧版发起本次升级时仍使用旧版的更新交接逻辑；新版独立助手在升级到本版后生效。
