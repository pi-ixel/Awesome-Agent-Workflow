# CodeCheck

从项目根目录运行随本 Skill 发布的 CLI：

```text
python <skill-dir>/scripts/codecheck.py
```

以 CLI 的退出状态和原生报告为检查结果，不另建包装报告，也不自行替代其扫描规则。CLI 不可用、执行异常或结果无法判断时，停止并说明阻塞；不得把失败解释为通过。

## 处理检查结果

- 检查通过：结束 CodeCheck，向调用方返回原生结果及实际执行的验证。
- 问题明确、修改局部，且不改变业务行为、公共接口、数据兼容、安全边界或已评审设计：直接修复，执行受影响测试并重新运行 CLI，直到通过。
- 修复影响上述任一边界、需要跨模块大范围调整，或存在多种需要取舍的方案：停止修改，向用户说明问题证据、影响范围和可选方案，等待决策。

问题等级只是线索，是否自动修复取决于修改影响。不得通过关闭规则、增加忽略项、弱化测试或改写结果来获得通过，也不顺带处理扫描范围外的问题。

若调用方维护代码重验流程，修改代码后先把控制权交还调用方完成重验；重新进入本 Skill 后再复查。
