# 轻量测试用例设计模板（dev 入口）

使用本模板创建或更新 `.sdd/{SR}/test-design.md`。本文件是独立测试设计成果物，基于同目录 `dev-design.md` 的方案、契约变更和验收标准生成；不得替设计补内容，不得拆分 AICoding 任务。

正式测试设计只输出验证结论，不记录目标抽取、候选用例、合并淘汰等推导过程。用例通过契约项名称、章节锚点或验收标准原文**引用** `dev-design.md`，不复述设计内容。

## 排版约定

第 3 节「最小充分测试用例集」是用例正文，**不得使用任何表格**——每条用例是一个列表条目（`##### TCn`），用列表逐项列出字段。表格只允许在第 1、2、4、5 节使用。第 3 节分层：`### 3.x 测试层级`（只建本项目能支撑的层级）→ `#### 3.x.y 功能点/场景` → `##### TCn` 用例条目。
